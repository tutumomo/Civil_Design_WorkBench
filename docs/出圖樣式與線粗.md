# 出圖樣式與線粗（autocad 出圖樣式）

> 2026-10-29｜來源：[`本項目的出圖規定(不定期新增).md`](../本項目的出圖規定(不定期新增).md) 的「autocad 出圖樣式」段。
> 這份說明「規定怎麼落到工具裡」：哪個檔案是唯一來源、哪些圖層用哪個顏色、出圖型式表怎麼來、品管怎麼擋。

## 一、規定本身

- 出圖型式：**monochrome.ctb**（灰階出圖）。
- 線粗依重要性分三級：**不重要 0.10 mm、一般 0.15~0.20 mm、重要 0.35~0.40 mm**。
- 圖面元件依重要性使用**不同顏色**，並放在**不同圖層**。
- 顏色 → 線粗：

| ACI | 顏色 | 線粗 |
|---|---|---|
| 1 | 紅 | 0.20 mm |
| 2 | 黃 | 0.20 mm |
| 3 | 綠 | 0.20 mm |
| 4 | 青（深藍綠） | 0.25 mm |
| 5 | 深藍 | 0.35 mm |
| 6 | 粉紅 | 0.40 mm |
| 7 | 白／黑 | 0.15 mm |
| 8 | 灰 | 0.10 mm（開啟調色與灰階） |

> 顏色 4 的 0.25 mm 不屬於三級中的任何一級，是中間值；實際使用時當作「次要主線」。
> 舊規定「黃色 ACI 2 禁用於房屋與圖框文字」仍然有效：色表允許 2，但工具不主動用 2，
> 免得文字出圖偏淡。

## 二、專案裡的唯一來源

`tools\drawing_rules.py`：

| 常數／函式 | 用途 |
|---|---|
| `LINE_WEIGHT_BY_COLOR` | 色表（1~8 → mm），**要改線粗只改這裡** |
| `IMPORTANCE_COLOR` | 重要性 → 預設顏色（minor 8／normal 7／line 1／mid 4／major 5／heavy 6） |
| `dxf_lineweight(mm)` | 規定 mm → DXF 370 值（DXF 沒有 0.10，取 0.09） |
| `add_plot_layer(doc, 圖層名, color=…, importance=…)` | 建圖層並同時設顏色與線粗 |
| `set_layer_plot(layer, …)` | 修正既有圖層 |
| `tag_plot_style(doc)` | 在 DXF 標頭寫 `TOMO_PLOTSTYLE=monochrome.ctb` |
| `plot_style_issues(doc, skip=…)` | 回傳顏色／線粗不符的清單（E17 用） |
| `PLAN_LAYER_COLORS`／`PLAN_LAYERS_OFF` | 現況平面圖 16 個標準圖層的顏色，與預設要關閉的圖層清單（site_basemap 與 apply_plot_style 共用） |

新圖層**一律用 `add_plot_layer()`**，不要直接 `doc.layers.add(name, color=…)`，
否則線粗會停在 ByLayer 預設值，E17 會擋。

## 三、各工具實際用色

| 工具 | 圖層 → 顏色（線粗） |
|---|---|
| `site_basemap.py` | 道路邊線 10 → 5（0.35）；水道 22 → 5；建物 20 → 4（0.25）；道路中心線 13、用地界 11 → 1（0.20）；路名 14、圖框 90~93 → 7（0.15）；影像 00~02、地籍界 12、Hatch 21/22 → 8（0.10） |
| `make_wall_section.py` | 牆身混凝土 30 → 5（0.35）；鋼筋 40 → 1（0.20）；尺寸 42 → 3（0.20）；排水孔 41 → 4（0.25）；剖面線 31、背填 32、開挖 33 → 8（0.10）；標註 43、圖例 91~93 → 7（0.15） |
| `paving_extent.py` | 刨鋪範圍 15 → 5（0.35） |
| `make_a3_sheet.py`（舊版） | 指北針 91、比例尺 92 → 7（0.15） |

`make_sheet.py` 會把底圖圖層整批匯入，顏色與線粗跟著 `site_basemap.py` 走；
它自己只新增 `23_河道標示`（顏色 5）。

### 舊圖怎麼改成新樣式

規定上線前產出的圖（例如 `AC刨鋪5cm工程_現況平面圖_A3.dxf`）**不必重跑整條產線**：

```bat
python tools\acad\apply_plot_style.py <圖.dxf>            只改 DXF
python tools\acad\apply_plot_style.py <圖.dxf> --publish  另出 DWG＋PDF＋PNG
```

它只做四件事：①依 `PLAN_LAYER_COLORS` 換圖層顏色並補線粗（保留圖層關閉狀態）、
②顏色已在 1~8 但不在表內的圖層補線粗、③把圖元自帶的顏色／線粗改回 BYLAYER
（`--keep-entity-colors` 可保留）、④寫入 `TOMO_PLOTSTYLE`。幾何與圖紙空間內容完全不動。

### 圖層名稱是跨工具契約

`01_公有地地籍影像`、`12_公有地地籍界線` 這兩個名字（**兩個「地」**）是 `site_basemap.py`、
`make_sheet.py`、`PLAN_LAYER_COLORS` 三邊共用的契約，少一個字就會變成孤兒圖層而被 E17 擋下。
改圖層名前，三個地方要一起改。

## 四、CTB 從哪裡來（重要）

AutoCAD 安裝版 `monochrome.ctb` 的顏色→線粗**與本規定不同**（2026-10-29 實測）：

| ACI | 安裝版 monochrome.ctb | 本規定 |
|---|---|---|
| 1 | 0.18 | 0.20 |
| 2 | 0.35 | 0.20 |
| 3 | 0.25 | 0.20 |
| 4 | 0.30 | 0.25 |
| 5 | 0.45 | 0.35 |
| 6 | 0.35 | 0.40 |
| 7 | 0.18 | 0.15 |
| 8 | 0.13 | 0.10 |

所以專案自帶一份：`tools\acad\plot\monochrome.ctb`（由安裝版複製後**只改線粗**，其他欄位不動）。
`tools\acad\acc.py publish` 預設就用這一份；檔案不在時才退回 AutoCAD 的 `monochrome.ctb`。
**不會**寫入 AutoCAD 安裝目錄或使用者的 Plot Styles 資料夾。

重建（公司若更新 CTB，重跑這一段）：

```bat
python tools\acad\ctb.py report "C:\Users\<使用者>\AppData\Roaming\Autodesk\AutoCAD 2022\R24.1\cht\Plotters\Plot Styles\monochrome.ctb"
python tools\acad\ctb.py build  "<上列安裝版路徑>" tools\acad\plot\monochrome.ctb
python tools\acad\ctb.py verify tools\acad\plot\monochrome.ctb
```

## 五、品管怎麼擋

| 代碼 | 檢查 | 擋什麼 |
|---|---|---|
| E17 | 有圖元的圖層，顏色須在 1~8，且圖層線粗須等於色表 | 直接 `layers.add` 造成線粗沒設、或用了色表外的顏色（例如 9） |
| E18 | DXF 標頭 `TOMO_PLOTSTYLE` 須等於 `monochrome.ctb` | 出圖型式沒記錄／被改成彩色的 `.ctb` |

沒有標頭記錄也算 E18 錯誤；舊圖可用 `apply_plot_style.py` 補寫，不需要重跑整條產線。

E17 也會警告「圖元自帶顏色或線粗與圖層不同」——那會蓋掉圖層設定，通常代表有圖元被硬設顏色。
圖層關閉（負色值，例如 `-8`）**不算違規**：E17 取絕對值判色，`apply_plot_style.py` 換色時也會保留關閉狀態。

## 六、已知限制

1. **DXF 沒有 0.10 mm 這個值**：DXF 370 只接受 0.09／0.13…，所以 0.10 以 **0.09** 記錄；
   實際出圖線粗以 CTB 為準（0.10）。
2. **CTB 沒有「調色／灰階」欄位**：monochrome.ctb 本身就是全黑（`DeviceGray`）輸出，
   已達灰階效果；若還要在出圖對話框勾「調色／灰階」，得人工勾。
3. **E17／E18 只看 DXF 設定，不讀 PDF 的實際線寬**：交件前仍要看一眼 PDF。
4. 本專案 CTB 的線粗索引取自 CTB 內部的 `custom_lineweight_table`；不同版本的 CTB 索引可能不同，
   所以 `ctb.py build` 一律以來源檔的對照表換算，不寫死索引。

## 七、改規定時的順序

1. 先改 [`本項目的出圖規定(不定期新增).md`](../本項目的出圖規定(不定期新增).md)。
2. 改 `tools\drawing_rules.py` 的 `LINE_WEIGHT_BY_COLOR`／`IMPORTANCE_COLOR`。
3. `ctb.py build` 重產 CTB，`ctb.py verify` 要 0 差異。
4. 跑 `tools\selftest\regression.py`（全案回歸）。
