# 工作台「設計圖」產線

> 適用：工程設計工作台（`http://127.0.0.1:8765/design`）的「設計圖」按鈕，以及背後的
> `tools\design\design_section.py`／`POST /api/design/section`。
> 版本基準：2026-11-04（CalVer `v2026.11.04-10`）。

## 1. 一句話

計算結果**全部通過**後，畫面才出現可按的「產生設計圖」；可選**圖面單位（m／cm）**與
**比例（1:10～1:250）**，一次產出斷面圖與配筋圖的 **DXF／DWG／PDF**。
計算未通過時按鈕停用，避免拿不合格的尺寸出圖。

## 2. 操作流程

1. 在左側選計算器、填參數、按「執行計算」。
2. 「計算結果」區塊下方出現「🖼️ 設計圖」面板。
   - 結果 `ok=false`：按鈕 `disabled`，滑鼠移上去顯示「計算結果未通過，請先修正參數」。
   - 結果 `ok=true`：可選圖面單位與比例，按「產生設計圖」。
3. 出圖約 5～15 秒（含經 `tools/acad/acc.py` 轉 DWG／PDF，預設後端 OpenCADStudio），完成後直接列出 6 個下載連結。
4. 檔案同時寫入 `out\design_sections\<calculator>\<YYYYMMDD_HHMMSS>\`，
   並附 `_drawing_meta.json`（比例、單位、檔案清單、當時的 case）。

### 圖面單位的語意

| 選項 | 效果 |
|---|---|
| `M（公尺）` | 尺寸標註顯示 `3.00 m`、右欄尺寸表以 m 計；比例尺刻度 `0／0.5／1`，標題註明「尺寸單位：m」 |
| `cm（公分）` | 尺寸標註顯示 `300 cm`、右欄尺寸表以 cm 計；比例尺刻度 `0／50／100`，標題註明「尺寸單位：cm」 |

**模型空間永遠是公尺**（`$INSUNITS=6`、`$MEASUREMENT=1`），`--unit` 只改
`DIMLFAC`／`DIMDEC`／`DIMPOST`、右欄尺寸表與說明文字裡的長度，**不改幾何**。
因此同一張圖切換單位不會改變比例、視口或圖形位置。

### 比例

- 選項：`auto`、1:10、1:20、1:25、1:30、1:40、1:50、1:60、1:75、1:100、1:200、1:250。
- `auto` 由斷面外廓自動挑「放得進 A3 可用區」的最小標準比例。
- 手選比例若放不下，出圖會**明確失敗**並回報可用比例（例如
  「模型 12.25×4.80 m 在 1:50 為 244.9×95.9 mm，超出 A3 可用區 183.0×249.4 mm」），
  不會偷偷改比例。此時改用 `auto` 或較大比例重跑即可。

## 3. 能力表

| 計算器 id | 圖說 | 產出 |
|---|---|---|
| `box_culvert` | 箱涵 | S-01 標準斷面圖、S-02 配筋圖 |
| `wall_stability` | 擋土牆（重力／半重力／懸臂） | S-01、S-02 |
| `counterfort_wall` | 扶壁式擋土牆 | S-01、S-02 |
| `mse_wall` | 加勁式擋土牆 RC 面版 | S-01、S-02 |
| `anchored_wall` | 錨定式擋土牆 | S-01、S-02 |
| `channel_hydraulics` | 排水溝 | D-01、D-02 |
| `slope_stability` | 邊坡 | E-01（無配筋圖） |
| `block_wall` | 疊式／砌石牆（蛇籠、格籠、漿砌石、乾砌石、三明治式） | S-01（不配鋼筋，無配筋圖） |
| `rc_beam` | RC 梁斷面 | B-01 梁斷面配筋圖（`tools/rc_section/make_rc_section.py`；支數由繪圖端推算並揭露） |
| `rc_column` | RC 柱斷面 | CL-1 柱斷面配筋圖（同上工具；主筋間距取引擎 `centre_spacing_mm`） |
| `foundation_isolated` | 獨立基腳 | F-1 平面＋剖面配筋圖（`tools/foundation_section/make_foundation.py`） |
| `foundation_combined` | 聯合基腳 | F-2 平面＋縱剖面配筋圖（同上工具） |
| `detention_basin` | 滯洪池 | P-1 平面＋縱剖面（`tools/basin_section/make_basin.py`；高程以池底為 ±0.00） |
| `sediment_basin` | 沉砂池 | P-2 平面＋縱剖面（同上工具；土池直壁示意，池壁另行設計） |
| `channel_cover` | 溝蓋版（RC 蓋版＋溝壁頂植筋） | C-01 溝蓋版詳圖（配筋＋植筋；工具 `tools/channel_cover/make_channel_cover.py`） |
| `steel_column` | 鋼構柱＋柱腳基板＋基礎螺栓 | SC-1 鋼柱柱腳詳圖（`tools/steel_base_section/make_steel_base.py`；平面＋立面、錨栓埋深；承台高度未由計算器決定，圖上斷線收尾） |
| `channel_profile` | 水面線（標準步法迴水） | L-1 水面線縱斷面圖（`tools/profile_section/make_profile.py`；H 樁號／V 高程兩種比例，垂直誇大 ≤ 30 倍，圖上不做自動量測標註） |
| `foundation_pile` | 樁帽／樁群載重分配 | FP-1 樁位配置圖（`tools/foundation_plan/make_foundation_plan.py`；樁以符號表示，樁徑與樁帽未由計算器決定，**非樁帽配筋圖**） |
| `settlement_assessment` | 沉陷與角變量評估 | FS-1 基腳沉陷配置圖（同上工具；逐基腳總沉陷、相鄰角變量表、超限標示） |
| `building_frame` | 2D 代表構架 | FR-1 構架立面圖＋構材配筋表（`tools/frame_section/make_frame.py`；梁主筋為引擎「每米寬」選筋、照列不換算；未實作分張，超過 1:250 放不下即報錯） |

全部 22 個計算器都有表態（三態，`capability()['status']`）：

| 狀態 | 意思 | 前端顯示 |
|---|---|---|
| `supported` | 上表 20 個，可出圖 | 「產生設計圖」面板 |
| `not_applicable` | 沒有幾何可畫（目前只有 `hydrology`），附理由 | 顯示理由 |
| `not_implemented` | 尚未提供（其餘 1 個：`drainage_network`，補齊進度見 `docs/設計圖產線補齊_工作計劃書_2026-11-11.md`） | 「此計算器尚未提供設計圖」 |

只有拿不到 capabilities（雲端／靜態版）才顯示「沒有出圖後端」。
此表與 `tools/selftest/design_section_selftest.py` 的 `EXPECTED_SUPPORTED` 對照，不同步會失敗。
SOP 見 `docs/計算器出圖SOP.md`。

新增可出圖的計算器時，只要在 `design_section.CAPABILITIES` 加一筆（`tool`／`model`／
`sheets`），前端會自動從 `/api/design/section/capabilities` 取得，不必改 HTML。

## 4. API

### `GET /api/design/section/capabilities`

回傳所有計算器的出圖能力、可選單位與比例：

```json
{"capabilities": {"box_culvert": {"supported": true, "units": [...], "scales": [...]}}}
```

### `POST /api/design/section`

```json
{
  "calculator": "box_culvert",
  "payload": { "...": "與 /api/design/run 相同的參數" },
  "unit": "cm",
  "scale": "auto",
  "project": "",
  "publish": true
}
```

回傳：

```json
{
  "ok": true,
  "unit": "cm",
  "scale": 75,
  "out_dir": "D:\\Civil_Design_WorkBench\\out\\design_sections\\box_culvert\\...",
  "files": [{"name": "S-01_箱涵標準斷面圖.pdf", "rel": "box_culvert/.../S-01_箱涵標準斷面圖.pdf", "kind": "pdf"}],
  "notes": [],
  "defaults_used": []
}
```

`rel` 是相對 `out\design_sections` 的路徑，前端據此下載：

### `GET /api/design/section/file?path=<rel>`

只允許讀取 `out\design_sections\` 下的檔案（已做絕對路徑前綴檢查，防目錄跳脫）；
依副檔名回傳 `application/pdf`、`application/acad`（DWG）、`image/vnd.dxf`、`image/png`。

## 5. 命令列（不經網頁）

```powershell
$env:PYTHONIOENCODING='utf-8'
python -E -P -X utf8 tools/design/design_section.py `
  box_culvert _temp\box_payload.json --unit cm --scale auto
```

`--no-publish` 只出 DXF（沒有 CAD 後端的環境可用）；`--project` 可覆寫標題欄工程名稱；`--drafter` 指定繪圖者。Linux／macOS 改用 `.venv/bin/python`。

## 6. 品管

- `make_box_section.py`／`make_wall_section.py` 產出後會自動跑
  `tools\a3_sheet\check_delivery.py`（E1~E18）。出圖失敗會讓 API 回 400，不會留下半成品連結。
- 比例尺刻度**只標數值**，單位寫在標題（「比例尺 1:75（尺寸單位：cm）」）；
  這是為了避免「0.5 m」與「1 m」在小比例尺（1:50 以下）疊字（E10）。
- 每次出圖後仍應把 PDF 轉 PNG 目視一次；自動檢核抓不到「圖說讀不懂」。
- 回歸：`tools\selftest\design_workbench_selftest.py` 已驗
  `/api/design/section/capabilities` 與前端「按鈕受計算結果控制」的字串。

## 7. 已知限制

1. **雲端（Cloudflare）版沒有出圖後端**：靜態版只有 Pyodide，沒有 Python、`ezdxf`、
   `accoreconsole`，所以面板會顯示「請於本機工作台執行」；運算功能不受影響。
2. **標題欄的設計／繪圖預設是 `Claude（AI）`**。繪圖者可用 `--drafter`（CLI）或 API 的
   `drafter` 欄位指定（2026-11-11 起 `wall_section`、`box_section` 皆生效；先前 `wall_section`
   的 `--drafter` 其實沒接到標題欄）。「設計」欄仍為預設值，正式交件前應改成技師姓名。
3. **圖面內容是「標準斷面＋配筋示意」**：不含翼牆、端牆、保護工、施工階段、
   開口補強、錨定／搭接詳圖；配筋表是設計結果的整理，不是可施工的鋼筋施工圖。
4. **配筋表的「支/m」與「每延米數量表」是設計值**：鋼筋損耗一律 6%（含搭接），
   與數量模型的 `rebar_kg_design` 同源；但仍應與預算書的鋼筋項對帳一次。
5. `slope_stability` 只有 E-01 斷面圖，沒有配筋圖（邊坡非 RC 構材）。
6. **FR-1 構架立面圖沒有分張**：跨數或樓層過多，連 1:250 都放不進 A3 時直接報錯
   （訊息明寫「尚未實作自動分張」），不縮非標準比例硬塞。大構架目前需自行拆分子構架。
7. **FR-1 的梁主筋欄是引擎「每米寬」選筋值**（As 為 mm²/m），不是該梁寬的實際支數；
   圖面說明第 3 條已揭露，支數換算仍以 B-01（`rc_beam`）為準。
8. **FP-1 不是樁帽配筋圖**：`foundation_pile` 不提供樁徑、樁長、樁帽尺寸與配筋，圖上樁是
   **符號**（圓的大小不代表樁徑），只表達樁位與逐樁軸力；FS-1 同理不含基腳埋深、高程與柱位。

- 2026-11-11（D9）：`building_frame` 可出 FR-1 構架立面圖＋構材配筋表；梁柱矩形由 `geometry` 與引擎構材編號（`B{樓層}_{跨}`／`C{樓層}_{軸}`）直接推算，配筋表逐列引用 `designs[]`（梁利用率取撓曲與剪力較大者）。梁主筋照列引擎「每米寬」選筋值、不在繪圖端換算支數；**未實作跨數／樓層分張**，1:250 仍放不下即明確報錯。順手把 `build_paper` 比例尺的 4 點 `add_solid`（OCS 出圖會畫成 X 交叉）改為兩個三角形。
