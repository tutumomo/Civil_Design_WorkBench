# 擋土牆改版作業計畫（3m→2.5m 重力式、5m→4.5m 懸臂式）

> 模式：**完整結構覆核** ＋ 2D 工程圖 ＋ 每公尺數量表 ＋ 分析報告書
> 原始素材：**僅照片**（無原始 DWG/PDF/計算書）
> 建立日期：2026-10-27

---

## 0. 本案的性質判斷

3m→2.5m、5m→4.5m 是**降低牆高**，屬結構變更而非等比縮圖。判斷依據：

- 降低 H → 主動土壓力合力 `Pa = ½·Ka·γ·H²` 減少，但**作用點距牆底**隨之改變 → 傾覆與滑動的力臂比改變
- 重力式：H 降低可縮減底寬與斷面（受滑動與承重控制），但有**最小構造斷面**下限
- 懸臂式：莖板受力大幅減輕（∝H²），但**底板**受力（由莖根部傳下之軸力與剪力）與鍵深受**最小構造**支配，不可等比縮
- 配筋：主筋受力減輕，但受**最小配筋率、裂縫寬度控制、構造規定**支配 → 可能不減反需維持

→ **本案的正確產出是「依新 H 重新設計的擋土牆」，而非「縮圖」。**

## 1.6 本案的規範合適性（已確認）

水土保持技術規範第118條牆型適用範圍：

- **重力式擋土牆：有效高 4 m 以下為原則** → 改版後 2.5 m ✔ 適用
- **懸臂式擋土牆：有效高 8 m 以下為原則** → 改版後 4.5 m ✔ 適用

原設計（3m / 5m）與改版後（2.5m / 4.5m）**兩者皆在適用範圍內**，改版未使適用性劣化。此點將在報告書「設計依據」章節列明。

## 2. S1 照片判讀 → 尺寸表（關鍵前置）

### 需要從兩張設計圖各抽出

**重力式擋土牆（原 3m）**
- 牆高 H、牆頂寬 B_top、底寬 B_base、牆身傾斜率（背面直立或放坡）、趾板長與厚、鍵深
- 排水孔：直徑、間距、離底高度、數量
- 混凝土：fc（f'c）、單位重
- 配筋：主筋直徑與間距、分布筋、保護層

**懸臂式擋土牆（原 5m）**
- 牆高 H、莖厚 T_stem（頂/底是否變厚）、底板總寬 B_base、趾板長 toe、踵板長 heel、底板厚 T_base、鍵深 key
- 排水孔同上
- 配筋：莖板主筋（通常豎向）、底板受力筋（上/下）、分佈筋

### 判讀方法與限制（務必知悉）

1. **比例推定**：照片無量測基準。以牆高 3000 / 5000 mm 為基準尺，其餘尺寸按像素比例換算 → **換算值一律標「推估值」**。
2. **信心分級**：每項標 A（圖上明寫，可直接讀）/ B（可由比例換算，誤差 <2%）/ C（須由比例推定或由構造推斷，誤差可能 5~10%）。
3. **C 級項目不進入計算**，先用合理假設，於報告標示並列入「待設計者確認」。
4. **鋼筋直徑與間距**多屬 B/C 級 → 我會給出判讀值與合理值對照，請你確認。
5. **視覺放大**：我會對照片做裁切放大後再判讀（尤其配筋圖與數量表），並回報每張照片的可讀程度。

## 3. S2 土工參數（完整結構覆核的必要輸入）

**照片不會包含土工參數**，這是本案最大的資訊缺口。完整覆核至少需要：

| 參數 | 符號 | 用途 | 若未知之處置 |
|---|---|---|---|
| 土壤單位重 | γ | 自重、土壓力 | 採一般砂土/黏土代表值並做敏感度分析 |
| 摩擦角 | φ | Ka、主動土壓力 | 同上 |
| 黏著力 | c | Ka（黏土時顯著） | 同上 |
| 地下水位 | – | 孔隙水壓、有效應力 | 採無水或不利水位兩種狀況檢核 |
| 填土超載 | q | 側向土壓力 | 採 10/20/50 kPa 三級敏感度 |
| 地盤承载力 | q_ult | 承重檢核 | 採 150~250 kPa 區間敏感度 |
| 地震 | kh | 耐震（台灣須考慮） | 依場址條件假設並在報告標示須以正式地勘報告覆核 |

**處置原則**：缺參數不阻擋工作，但每一個假設值都必須 (a) 明列於報告書「設計假設」章節、(b) 以敏感度分析呈現（哪個參數主導結果）、(c) 結論標示「須以正式地勘與結構精算覆核」。

> **使用者已授權採代表值 + 敏感度分析**（2026-10-27 確認）。

### S2.1 依水土保持技術規範第121條的排水配置（已可先行定案）

排水孔與伸縮縫配置**不依賴土工參數**，可直接進入 CAD 參數表與數量表，屬**不受判讀誤差影響的確定項目**：

- 排水孔直徑 ≥ 5 cm（第121條）

- 須有防止阻塞之設施：背填透水性良好材料 ＋ 反濾層
- 伸縮縫每 20~40 m 1 處（第121條）→ 取較嚴 **20~30 m**

## 4. S3 結構計算項目

### 4.1 載重與土壓力
- 靜止土壓力、**主動土壓力 Rankine / Coulomb**（依牆背排水條件判定）
- 地震時**動態土壓力**（Mononobe-Okabe 或 Newmark）
- 水壓力（若地下水存在）
- 超載 → 側向壓力增量

### 4.2 穩定檢核

**允許值採「三套規範取較嚴者」策略**（見 §1.5 規範對照）。以水土保持技術規範為主要控制者如下（已自農業部法規共用系統取得條文原文，2026-10-27 查證）：

| 檢核 | 水土保持技術規範（114.05.07 修正）條文 | 允許值 | 建築/公路系 |
|---|---|---|---|
| **滑動** | 第120條一 | **常時 FS ≥ 1.5；地震時 FS ≥ 1.2** | 公路系通常要求更高（≥1.5~2.0） |
| **傾倒** | 第120條二 | **常時 FS ≥ 2.0；地震時 FS ≥ 1.5** | 公路系常採 ≥1.5~2.0，取較嚴 |
| **合力作用點** | 第120條二(���) | **岩盤基礎：基礎底寬 1/2 中段內；土層基礎：1/3 中段內** | 兩系均有此規定，取較嚴（1/3） |
| **基礎承重** | 第120條三 | **安全係數 ≥ 3**（在土壤容許承載力內） | 兩系一致 |
| **牆身應力** | 第120條四 | 須在材料容許應力範圍內 | — |
| **排水孔** | 第121條 | **直徑 ≥ 5 cm，每 2 m² 至少 1 孔**，須有防阻塞設施 | 水土保持系特有且明確 |
| **伸縮縫** | 第121條 | **長度每 20~40 m 加設 1 處** | 公路系常採 20~30 m，取較嚴 |
| **作用力組成** | 第119條 | 自重、加載荷重、土壓力、水壓力、**地震力**、基礎承載力 | — |

補充檢核（非水土保持技術規範明文，依專業技師判斷）：深層滑動（黏土）、趾板前被動土壓、擋土牆與邊坡共構檢核。

> **「地震時滑動 FS ≥ 1.2」是本案的關鍵值**：地震工況常控制斷面尺寸，尤其懸臂式。不能只做常時檢核。

### 4.2.1 水土保持技術規範的**適用性前提**（本案必須遵守）

已查證條文（第118條、第120條、第121條等）：

| 條文 | 內容 | 對本案的意義 |
|---|---|---|
| **第118條** | **重力式擋土牆：有效高在 4 m 以下為原則** | 原 3m 重力式 → 改 2.5m，**仍在適用範圍內** ✔ |
| **第118條** | **懸臂式擋土牆：有效高在 8 m 以下為原則** | 原 5m 懸臂式 → 改 4.5m，**仍在適用範圍內** ✔ |
| **第118條末項** | 有效高指**露出地面之高度**；經專業技師分析安全無虞者不在此限 | 判讀「有效高」時以露出地面高為準（牆頂高於原地面者只算露出段） |
| **第117條** | 擋土牆係指為攔阻土石、砂礫及類似粒狀物質所構築之構造物 | 適用性確認：本案兩種牆型均屬 |
| **第59條** | 坡面保護：混凝土擋土牆、砌石擋土牆、疊式擋土牆等 | 牆背須配合**植生／排水**措施，非僅結構 |
| **第121條但書** | 背填有適當排水設施者，排水孔與伸縮縫不受前二項限制 | 但本案仍建議照規定設置，不採但書 |
| 背填要求條文 | 擋土牆之背填應以**透水性良好之材料** | 背填料（級配碎石）須列入數量表與圖說 |
| 不得共構條文 | 擋土牆**不得作為建築物外牆使用**（經建築主管機關同意者除外） | 若本案位於建築基地周邊，須確認有無共構需求 |

**結論：兩種牆型在改版後（2.5m / 4.5m）均落在水土保持技術規範第118條的適用範圍內**，此為本次改版在規範上的合適性依據，將在報告書專章說明。

### 4.3 構材設計
- **懸臂式**：莖板按懸臂梁（主筋）、底板按懸臂/支承梁（趾板上、下緣主筋，踵板受力筋）
- **重力式**：牆身按受拉構材檢核裂縫（無筋或溫度筋）
- 鋼筋：最小配筋率、最大間距、錨固長度 la、搭接、保護層
- 裂縫寬度控制、挠度（懸臂莖板）
- 溫度筋與分佈筋、伸縮縫間距（**水土保持技術規範第121條：每 20~40 m 一處，取較嚴者 20~30 m**）
- **排水孔**：直徑 ≥ 5 cm、每 2 m² 至少 1 孔（第121條）→ 直接影響牆身鑽孔數量與數量表

### 4.4 斷面決定
依 4.2/4.3 反求最小斷面 → 決定 H=2.5 / 4.5 時的新 B_base、T_stem、T_base、趾/踵長 → 這些數值即新 CAD 的參數。

> **產出是「重新設計的斷面」，不是原圖縮圖。** 原圖尺寸僅作為起點與風格參考。

## 7. 風險與誠實聲明

| 風險 | 影響 | 處置 |
|---|---|---|
| 照片判讀誤差 | 全部下游尺寸偏差 | 分級標示＋你逐項確認；C 級不進計算 |
| 無原始圖面語彙 | 新舊圖風格差異 | 依原照片可辨識者模仿，說明差異 |
| 無土工參數 | 覆核結果僅代表假設情境 | 敏感度分析＋明確聲明（已授權採代表值） |
| 無計算書 | 原設計意圖不明 | 以結構合理性反推，於報告標示 |
