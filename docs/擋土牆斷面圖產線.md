> 2026-10-28 建立｜補「設計圖」軸的第二種圖：**標準斷面圖**（現況平面圖之外）
> 擋土牆 → S-01；排水溝 → D-01。`make_sheet.py` 只會做現況平面圖，不做斷面。

## 1. 一句話

**一份 `case.json`（`quantities.model = wall`）→ A3／1:20 標準斷面圖 DXF＋DWG＋PDF，並用既有的 `check_delivery.py` 驗 E1~E18。**

在專案根目錄執行（先 `cd` 到專案根目錄，以下路徑皆為相對路徑）：

```bat
set PYTHONIOENCODING=utf-8
python tools\wall_section\make_wall_section.py ^
  cases\擋土牆3m重力式\case.json --scale 20 ^
  --out cases\擋土牆3m重力式\S-01_擋土牆標準斷面圖.dxf --publish
```

或直接走交付包（會自動產斷面圖並驗圖）：

```bat
C:\Python312\python.exe tools\case_package\case_package.py cases\擋土牆3m重力式\case.json
```

`case.json` 要加一段：

```jsonc
"section": { "scale": 20, "out": "cases/擋土牆3m重力式/S-01_擋土牆標準斷面圖.dxf" }
```

## 2. 支援三種斷面

### 2.1 排水溝（`model: channel`）

斷面＝U 型（外框減內腔），圖號 **D-01**：

| 元素 | 內容 |
|---|---|
| 混凝土 | 外框（W × (H+tb)）減內腔（B × H），內腔留空 |
| 剖面線 | 只填混凝土區（Hatch 帶內腔洞徑） |
| 尺寸 | 內寬 B、溝深 H、壁厚 t、底厚 tb、外寬 W |
| 圖例 | 溝壁內側筋／外側筋／溝底筋（D13@200）、保護層 50 mm |
| 部位 | 1 溝壁、2 溝底、3 通水斷面、4 基礎開挖線 |

> 排水溝斷面**沒有**「41_排水孔」圖層 → `case_package` 的必要圖層清單已依模型切換
> （channel 檢查 `34_溝內腔`，wall 檢查 `41_排水孔`）。這是實測踩到的 E14。

### 2.2 擋土牆：三種牆型（斷面幾何不同，不能共用）

| `wall_type` | 斷面 | 斷面積公式 | 適用 |
|---|---|---|---|
| `gravity`（重力式） | **梯形**：正面鉛直、背面斜；頂寬 T、底寬 BL | `(T + BL)/2 × H` | 第118條：有效高 ≤ 4 m |
| `semigravity`（半重力式） | **厚牆＋底板**：牆頂寬 T、前後坡、底板 BL×BT | `BL×BT + T×(H−BT) + 0.5×(S1+S2)×(H−BT)²` | 第118條：有效高 ≤ 4 m |
| `cantilever`（懸臂式） | **薄牆身 + 底板**：牆身 T×H，底板 BL×BT | `T×H + BL×BT` | 第118條：有效高 ≤ 8 m |

**同高 3 m 的差距**：重力式 2.85 m³/m vs 懸臂式 0.99 m³/m（**2.9 倍**）。這是重力式的本質代價，也是選型時最該看的一個數字。

> ⚠️ **教訓**：曾把「薄牆身 250 + 底板 600×400」誤標為重力式。那組幾何是懸臂式特徵。
> 名稱與幾何不符的圖，比畫錯更危險 —— 看圖的人會照著錯誤的名字去理解。

### 配筋圖的三個坑

1. **配筋表會被舊的「鋼筋圖例」覆蓋**：`rows` 在後續 `if is_chan/elif is_grav/else` 分支被重新賦值，
   兩套內容疊在同一位置 → E10 疊字。要在 `if rebar_schedule:` 時把 `rows` 鎖成空清單。
2. **DXF 文字不可含 Markdown 星號**：`**配筋圖**` 在 SHX 字型下變成「××配筋圖××」；
   且「撓」字在 CHINA1.SHX 缺字 → 改寫成「彎矩」。圖說文字只能用常見字，不要用 Markdown 標記。
3. **分支順序會讓配筋圖印上「鋼筋為示意」**：`if is_chan:` 在 `elif rebar_schedule and is_chan:`
   之前就先攔走，導致 D-02 配筋圖的說明還是標準斷面圖那套 —— 跟事實正好相反。
   要改成 `if is_chan and not rebar_schedule:`。**「圖說內容與圖的性質相反」是最難靠肉眼發現的錯。**

## 6. 踩坑紀錄（實際發生過的）

| # | 現象 | 原因 | 解法 |
|---|---|---|---|
| 1 | PDF 整張空白，只有圖框 | 刪樣板版面時把**圖框與標題欄一起刪掉**了 | 不刪版面，改「沿用 + 清舊視口 + 改名」 |
| 2 | 刪版面失敗且靜默 | 刪到 active layout，ezdxf 拋錯被 `try/except` 吞掉 | 先建/設好新版面再刪舊的；**不要吞例外** |
| 3 | PDF 文字層 0 字元 | gbenor.shx（SHX 字型）出圖會轉成向量筆畫，不是字型 | 正常行為，用 PNG 目視驗，不要用 `get_text()` 判斷有沒有字 |
| 4 | 斷面內只有一條斜線 | hatch pattern scale 用了 `scale/20`（1:20 → ≈3.2 m 間距，比牆還高） | 改成 `(1.5 mm × N / 1000) / 3.175`（ANSI31 基準間距 3.175 unit） |
| 5 | 比例尺長度差 2.5 倍 | 誤以為 1 m 於 1:N = N mm | 正解：**1 m at 1:N = 1000/N mm**（1:20 → 50 mm） |
| 6 | 重力式背填填進牆體 | 背填從 x=0 起算，但重力式背填要沿斜面往後 | 依牆型算 `b_lo/b_hi`，背填多邊形跟著斜面 |
| 7 | 「≥」在圖上變「?」 | SHX 字型無此字元 | 改寫成文字「5 cm 以上」 |
| 8 | 工程名稱被截斷 | `project[:30]` | 超過 26 字折兩行，不截斷 |
| 9 | 標題欄疊字 | 在樣板標籤旁**新增**文字 | 改成**替換樣板既有文字** + 必要時才 fill |
| 10 | 尺寸小數點變「,」 | dimstyle 未設小數分隔符 | `ds.dxf.dimdsep = 46`（`.`） |
| 11 | **垂直尺寸量到 0.00** | `add_linear_dim(angle=0)` 量的是水平投影，鉛直線段自然是 0 | angle 依 p1/p2 自動判斷（鉛直給 90） |
| 12 | 工程名稱壓到「設 計 單 位」 | DXF 的 TEXT **是單行實體，`\n` 無效**（只有 MTEXT 能換行）；折成兩個實體又與下排相撞 | 標題欄改用**短案名**（完整名稱留給報告封面），超過 34 字加「…」 |
| 13 | 排水溝斷面 E14 缺 41_排水孔 | `case_package` 對所有斷面圖都要求排水孔圖層 | 必要圖層依 model 切換（channel → `34_溝內腔`） |

## 7. 已知限制

1. **只做標準斷面圖**，不做配筋圖（S-02）—— 鋼筋僅示意，須依結構計算結果另行設計。
2. **不做結構計算**（滑動／傾倒／承載）—— 需土工參數，屬技師職責。
