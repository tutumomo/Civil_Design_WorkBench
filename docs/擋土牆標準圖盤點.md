## 6. 使用限制與風險

1. **公路局 601 重力式的斷面尺寸表以文字＋尺寸實體儲存**，本次以 TEXT 掃描無法完整抽出數值欄；實際套用該表時須在 AutoCAD 開檔對照。本清單對 601 只確認到「甲／乙／丙三種＋選用參考表＋標準斷面圖」的存在，未逐格驗證其數值。
2. **601、602~605、510 的表格數值未逐格驗證**（本次僅驗證 613、615、618 的數值列與 TYPE-C/D 的數量表）。
3. **LT-/LTT-/PK- 檔名中的數字是長度代碼，非牆高**；D- 系列數字是牆高 cm，la- 系列是底寬 cm。不得混用。
4. 所有 DWG 的 `$INSUNITS` 為 0（未定義），單位須依圖面標註判讀，**不可依檔案 metadata 推斷**。
5. `常用元件` 內 `防落石柵(...)(誤用苗62-1圖).DWG` 檔名已標註誤用，不應直接引用。
6. 預覽 PNG 由 ezdxf matplotlib 後端渲染，**不等同 AutoCAD 實際出圖**；正式引用前仍須以 AutoCAD 開啟 DWG 確認。
7. 本清單僅盤點**檔案存在性與可讀出的尺寸表**；未做結構計算或穩定分析，擋土牆選型仍須依背填土、基底承載力與排水條件核算。
