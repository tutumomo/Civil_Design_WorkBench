### 取得方式（可重跑）

```bat
:: 全文（HTML → 純文字）
curl -4 -L -A "Mozilla/5.0" "https://law.moa.gov.tw/LawContent.aspx?id=FL014521" -o _tmp_lawcontent.html
:: 再用 Python 去標籤（見本檔 §4 附的抽取方式）

:: 修正條文公報 PDF
curl -4 -L -A "Mozilla/5.0" ^
  "https://law.moa.gov.tw/Download.ashx?FileID=43013&id=FL014521&type=LAW" ^
  -o "data\法規\水土保持技術規範_1140507_公報.pdf"
```

**踩到的坑**：
1. `law.moa.gov.tw` 直接 `curl` 會回 **HTTP 000**（連線失敗）→ 加 `-4`（強制 IPv4）即 `HTTP 200`。
2. 條號在 HTML 裡是**阿拉伯數字加空白**（`第 84 條`），不是中文數字（`第八十四條`）；用中文數字去搜會完全找不到。
3. `LawContent.aspx?media=print` 反而取不到內容（截斷），要抓 **`LawContent.aspx?id=`** 的一般頁再自己剝標籤。

## 2. 對本工作區的直接影響：三個參數改了

先前 `tools\design\channel_hydraulics.py` 用的是「工程慣例值」，抓了條文後發現**三處與條文不符**：

| 項目 | 先前（慣例值） | 條文值 | 條號 |
|---|---|---|---|
| 最小容許流速（混凝土／RC） | 0.6 m/s | **0.8 m/s** | 第 85 條一 |
| 最大容許流速（混凝土常流水） | 3.0 m/s | **4.57~6.10 m/s**（程式取 4.57 保守） | 第 85 條二(一) |
| 出水高 | max(0.20, **0.20**h) | max(0.20, **0.25**h) | 第 86 條 |

改成條文值後重跑排水溝案：流速 1.60 m/s 仍落在 0.8~4.57 內，**各項檢核全部通過**，斷面不需變更。

> 教訓：慣例值與條文值差一點點，看起來都能過 —— 但「看起來都能過」正是最危險的情況。
> 若當初流速是 0.7 m/s，慣例值會放行、條文值會擋下，差別就在這裡。

| ID | 條號 | 標題 | 本案用途 |
|---|---|---|---|
| SWH-78 | 78 | 道路排水設施 | 邊溝坡度 >0.2%（山區農路 >0.5%）、側溝最小寬深 30 cm、橫向排水每 150 m |
| SWH-83 | 83 | 坡地排水系統之設計洪水量 | 重現期 10 年（坡地農地）／25 年（其他非農業） |
| SWH-84 | 84 | 平均流速 | 曼寧公式 v=(1/n)R^(2/3)S^(1/2) |
| SWH-85 | 85 | 最大容許流速 | 混凝土/RC 最小 0.8；混凝土常流水最大 4.57~6.10；無常流混凝土 6.1、RC 12 |
| SWH-86 | 86 | 出水高 | 設計水深 25%，最小 20 cm |
| SWH-87 | 87 | 涵管 | 不滿流，水深 ≤ 內徑 0.75 |

### 仍然「沒有條文」的兩項（誠實標示）

1. **曼寧粗糙係數 n** —— 第 84 條只給公式，**沒有規定 n 值**。混凝土一般取 0.013~0.015，屬材料選定。工作台現提供常用材料範圍下拉預設，但仍保留自訂數字框，不能把預設值當成法定固定值。
2. **容量安全係數 1.2** —— 規範未規定，這是本工作區的保守加成（報告中標為「慣例」）。

## 4. 全文抽取方式（HTML → 純文字）

```python
import re, html
h = open("_tmp_lawcontent.html", encoding="utf-8", errors="replace").read()
m = re.search(r'id="ctl00_cp_content_lawcontent1_divLawContent"', h)
body = h[m.start():] if m else h
body = re.sub(r"<(script|style).*?</\1>", " ", body, flags=re.S | re.I)
body = re.sub(r"<br\s*/?>", "\n", body, flags=re.I)
body = re.sub(r"</(p|div|tr|li|h\d)>", "\n", body, flags=re.I)
body = re.sub(r"<[^>]+>", "", body)
body = html.unescape(body).replace("\u3000", " ").replace("\xa0", " ")
lines = [re.sub(r"[ \t]+", " ", l).strip() for l in body.split("\n")]
open("水土保持技術規範_1140507_全文.txt", "w", encoding="utf-8").write("\n".join(l for l in lines if l))
```

抽取後可驗證：應有 **219 個條號字串、212 個唯一條號**（第 1 條起、含「之 1」子條）。
