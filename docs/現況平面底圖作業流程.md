# 現況平面圖作業流程（取代 Google 截圖描圖）v2

## 適用情境
小型案件無測量，需要案址周邊的平面配置線稿（道路、建物、用地範圍）。

## 指令
```
set PYTHONIOENCODING=utf-8
cd /d <專案根目錄>\tools\site_basemap
C:\Python312\python.exe site_basemap.py --lat 24.110991 --lon 120.657854 --name 福田路案 > _log.txt 2>&1
C:\Python312\python.exe render_dxf.py "<專案根目錄>\福田路案\現況底圖\福田路案_現況平面圖_TWD97.dxf"
```
- 經緯度：Google 地圖對案址按右鍵，第一行即是（只取座標，不用其影像）。
- 選項：`--width 360 --height 220`（範圍 m）、`--scale 1000`（出圖比例，影響字高、Hatch 間距、比例尺；**須為標準比例尺**，並應與 A3 出圖比例一致，見 `本項目的出圖規定(不定期新增).md`）、`--out`、`--no-osm`。
- 約 1.5～2 分鐘，必超過遠端 60 秒，請輪詢 log（踩坑紀錄 A、G）。

## 產出（`<案名>_現況平面圖_TWD97.dxf`，TWD97 TM2、公尺、TOMO 字型）
| 圖層 | 內容 | 預設 |
|---|---|---|
| 10_道路邊線_現況 | 電子地圖道路區外框（已平滑，扣除貼建物段） | 開 |
| 11_道路用地界_地籍 | 自動判定為道路的公有地地號聯集外框 | 開 |
| 12_公有地地籍界線 | 全部公有地地號界線 | 關 |
| 13／14 | OSM 道路中心線、路名 | 開 |
| 20_建物／21_建物_HATCH | 建物輪廓（依主軸正交化）＋ANSI31 | 開 |
| 22_水道 | 水道輪廓 | 開 |
| 90～93 | 圖框、指北針、比例尺（圖示＋S=1/xxx）、資料來源說明 | 開 |
| 00／01／02 | 正射影像、公有地地籍影像、電子地圖影像（外部參考，須同資料夾） | 關 |

另有 `_check_overlay.jpg`（線稿疊正射影像）、`_check_linework.jpg`、`*_render.png`（DXF 實際渲染）。

## 交件前人工檢查
1. 看 `_check_overlay.jpg`：建物與道路線是否貼合影像現況（電子地圖可能比影像舊）。
2. 看 `*_render.png`：Hatch、孤島、指北、比例尺是否正常。
3. 連棟建物如需分戶，依影像補分戶線。
4. 用地界址涉權利時，以地政事務所地籍圖謄本為準。
5. 本圖**不含高程**；排水坡度、牆高需另行量測。

`<專案根目錄>\描圖測試_平面圖\描圖測試_現況平面圖_TWD97.dxf`（臺中市南區福田路與福田三街口）。

## 出 A3 圖紙空間（指定比例）v1

上面產出的是**模型空間**線稿。若要交 A3 圖紙（含圖框、視口、標題欄），用 `tools\a3_sheet\make_a3_sheet.py`：

```
set PYTHONIOENCODING=utf-8
C:\Python312\python.exe <專案根目錄>\tools\a3_sheet\make_a3_sheet.py ^
  --base  <案名>_現況平面圖_TWD97.dxf ^
  --frame <專案根目錄>\A3圖框.dwt ^
  --meta  basemap_meta.json ^
  --scale 600 ^
  --out   <案名>_現況平面圖_A3.dxf ^
  --title "臺中市南區現況平面圖" --drawing "現況平面圖" --designer "繪圖者" --date "2026.10.22"
```

- `--frame` 直接吃 `.dwt`（內部自動用 CADCraft 轉 DXF）。
- **`--width/--height` 要先跟視口對齊**：模型覆蓋寬 = 視口寬(mm) × 比例分母 / 1000。
  A3 圖框可用區 400.24 × 258.45 mm，故 1:600 → 240.1 × 155.1 m。
- 工具會自動：刪掉線稿自帶的 `90~93` 圖例層、刪掉樣板壞掉的舊視口、重建視口、
  在圖紙空間加指北針與比例尺、填標題欄、併檔前補 TOMO 樣式。
- 出圖檢核：`cadcraft-cli.exe run 成果.dxf --cmd 'plot {"path":"x.pdf","layout":"全區工程位置圖","fit":true}'`
  → 得到的是 **PDF**，再用 PyMuPDF 轉 PNG 目視。

詳細踩坑見 `docs\踩坑紀錄.md` 第 I 節。

## 出圖：模型 → A3 配置 → DWG＋PDF（2026-10-22 比拼任務後建立）

### 兩步完成
```
set PYTHONIOENCODING=utf-8
cd /d <專案根目錄>\tools\site_basemap
C:\Python312\python.exe site_basemap.py --lat <緯度> --lon <經度> --name <案名> --scale <比例> --width <W> --height <H> --out <資料夾>\model > _log.txt 2>&1
cd /d <專案根目錄>\tools\a3_sheet
C:\Python312\python.exe make_sheet.py --model <資料夾>\model\<案名>_現況平面圖_TWD97.dxf --scale <比例> --title 現況平面圖 --project <工程名稱> --out <資料夾>\<檔名>.dxf --publish > _log.txt 2>&1
```
- **範圍要夠**：`--width ≥ 400.3×比例/1000 + 20`、`--height ≥ 258.4×比例/1000 + 20`（公尺）。
  1/600 → 260×175；1/500 → 220×150；1/1000 → 420×280。不足時 make_sheet 會警告。
- 兩支都超過遠端 60 秒，輸出導 log 再輪詢。
- 產出：`.dxf`、`.dwg`（AutoCAD 2018）、`.pdf`（AutoCAD 實際出圖）、`_pdf.png`（PDF 預覽，**必看**）。

### make_sheet 做了什麼
1. 讀 `tools\a3_sheet\A3圖框_template.dxf`（由 `A3圖框.dwt` 轉出；樣板改版時用 `--dwt` 重新轉）。
2. 模型空間匯入描圖（工具自帶的 90～93 圖框類圖層不匯入），影像圖層與公有地地號線預設關閉。
3. 河道面以 OSM 名稱標註（查不到標「河道」）。
4. 配置「全區工程位置圖」建 viewport：中心＝案址、比例鎖定，**非矩形裁切**挖出三區：
   左下說明＋比例尺、右上指北針、右下技師執業圖記。
5. 圖標欄填圖名、工程名稱、比例；業主／設計／繪圖／日期欄**不自動填**，交件前人工補。
6. 自檢（比例、裁切、鎖定、TOMO 字型）→ `--publish` 交給 `tools\acad\acc.py` 由 AutoCAD 核心存 DWG、出 PDF。

### 換樣板時
在 `make_sheet.py` 的 `PROFILE` 新增一組：配置名、內框 X0/Y0/X1/Y1、三個挖空區角點。
先用 `acc.py todxf 新樣板.dwt 輸出.dxf` 轉出，再參考 `測試任務_Claude\inspect_template.py` 量座標。

### 標準三步（照這個順序做）

```bat
:: 1. 產模型線稿（建物優先吃臺中市建物圖 SHP，見 AGENTS.md §8.3）
C:/Python312/python.exe <專案根目錄>/tools/site_basemap/site_basemap.py ^
  --lat 24.124736542844435 --lon 120.66010997304573 --width 240 --height 155 --scale 600 ^
  --name <案名> --out <工作區>\<案名>_現況平面圖_TWD97.dxf

:: 2. 併 A3 圖框＋出 DWG/PDF（canonical 工具，已內建三區挖空避讓）
C:/Python312/python.exe <專案根目錄>/tools/a3_sheet/make_sheet.py ^
  --model <工作區>\<案名>_現況平面圖_TWD97.dxf --scale 600 ^
  --title 現況平面圖 --project <工程名稱> ^
  --out <工作區>\<案名>_現況平面圖_A3.dxf --publish

:: 3. 交件品管（退出碼 0 才可交件）
C:/Python312/python.exe <專案根目錄>/tools/a3_sheet/check_delivery.py ^
  <工作區>\<案名>_現況平面圖_A3.dxf --scale 600 --require-dwg ^
  --require-layer 10_道路邊線_現況 --require-layer 20_建物 --require-layer 22_水道
```

### 為什麼第 2 步不要用 `make_a3_sheet.py`
`make_sheet.py` 用**非矩形 viewport 裁切**挖掉「左下說明區／右上指北針區／右下技師執業圖記區」，
所以標註不會壓到標題欄；`make_a3_sheet.py` 只是把視口鋪滿內框，標註要自己找位置，容易壓字。
第二輪起以 `make_sheet.py` 為準。

### 檢核沒過怎麼辦
| 錯誤 | 修法 |
|---|---|
| E9 壓字 | 把標註移到 `y≥29.5` 的可繪區內；說明用 MTEXT 一次寫，起點 `x=11.5, y=31.5` |
| E10 疊字 | 標題欄填值的 x 起點要移到欄位標籤右側（84.7／155.9／231.5／282.5／384.4 之後） |
| E11 漏 Hatch | 建物逐棟建 Hatch（Normal 樣式、外框逆時針／內洞順時針），不要整批塞進 1 個 HATCH |
| E14 必要圖層空 | 回頭檢查 `site_basemap.py` 的參數與資料源，別急著排版 |
| W4 缺 DWG | 加 `--publish`，或 `acc.py publish <dxf> <dwg>` |

### 取得步驟

1. **取資源清單（平台 `/api/v1/` 需帶 id，其他參數會回 400）**
   ```
   GET https://opendata.taichung.gov.tw/api/v1/dataset.info?id=cfc32525-e67f-4c5f-b6d4-d2f575deb666
   → payload.resources[0].url
   ```
   註：`opendata.taichung.gov.tw/search/<pid>` 是 Nuxt 空殼，直接爬 HTML 抓不到連結（本輪已驗證：頁面內無「建物」字樣、`/api/` 未帶 id 一律 `NO_AUTH`）。
2. 該 `resource.download` 下載到的是**CSV 索引**（`臺中市建物_114.csv`），不是幾何；內含欄位 `114年建物地圖網址`＝Google Drive 分享連結。
3. Google Drive 用 `https://drive.google.com/uc?export=download&id=<fileId>` 直接抓，得 **7z（78 MB）**；不需 gdown。
4. `7z x` 解開 → `01-SHP\114期末_B0001_1216n.{shp,dbf,shx,sbn,sbx,prj,cpg,shp.xml}`（解開後 495 MB）。
