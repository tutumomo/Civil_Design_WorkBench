# 環境需求與自動配置

> 這份文件回答兩個問題：**這個專案需要什麼才跑得起來**、**怎麼讓 AI 幫你一次裝好**。
> 專案本身只用相對路徑（見 `tools/project_paths.py`），資料夾搬到任何磁碟、任何作業系統都能跑；
> 但部分功能要靠外部程式（ArtCraft、AutoCAD、SolidCraft），那些是平台相關的，所以列清楚。
> **macOS 使用者請先讀 §8.5「macOS 專用配置」**（沒有 `*-cli`、沒有 `python.exe`、沒有 AutoCAD）。

## 0. 一句話版本

```bash
python -m pip install -r requirements.txt     # Python 依賴
python tools/project_paths.py                 # 只檢查，逐項列出 OK／—
python tools/project_paths.py --install       # 檢查「並自動補裝」缺漏的第三方工具
```

> ⚠️ **`project_paths.py` 單獨執行只會回報，不會安裝任何東西。**
> 必備工具共四項。**OpenCADStudio、Open CalcSheet Studio**（皆為使用者 fork 的**本地化 TW 版**：「Open CAD Studio.TW」「Open CalcSheet Studio TW」，可與上游版並存，專案只綁 TW 版）要加 `--install` 才會自動安裝；**ArtCraft Launcher**（[`storytold/craft-launcher`](https://github.com/storytold/craft-launcher)，內含十幾套開源軟體，可平替 Adobe、Office、CAD）與 **Blender** 是手動安裝，`--install` 只偵測並印取得指引（缺少時退出碼非 0）；IngeTrazo 為選用，同樣只印指引。
> 先看計畫用 `--install --dry-run`；只補單一項用 `--install --only OpenCADStudio` 或 `--only OpenCalcSheet`。
> Open CalcSheet Studio 裝好後還要「開程式一次、啟用 MCP/API」再跑 `python tools/crosscheck/ocss_crosscheck.py register-mcp --apply`，見 §8.6。
> 安裝器實作在 `tools/install/toolchain.py`，行為見 §9。

> **macOS 請在專案內的虛擬環境安裝**（見 §8.5）：
> `python3 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt`，
> 之後所有指令用 `.venv/bin/python`（或設 `CIVIL_AI_PYTHON=.venv/bin/python`）。

`tools/project_paths.py` 是本專案唯一的環境探測入口：它會告訴你 Python 版本、專案根目錄、
規範索引在不在、13 套 ArtCraft 找到幾套、AutoCAD／SolidCraft／Blender／CAD 字體有沒有。

## 1. 必要條件（沒有就跑不動核心功能）

| 項目 | 版本 | 用途 | 沒有會怎樣 |
|---|---|---|---|
| Python | **3.10+（建議 3.12）** | 全部工具 | 無法執行 |
| numpy | ≥1.26 | 設計計算（`tools/design/*`） | 設計軸全掛 |
| ezdxf | ≥1.3 | 產生／讀取 DXF | 出圖軸全掛 |
| matplotlib | ≥3.8 | 圖表、斷面預覽 | 部分出圖與圖表失敗 |
| shapely | ≥2.0 | 幾何運算（範圍、緩衝） | 土方／刨鋪範圍計算失敗 |
| pyproj | ≥3.6 | TWD97 ↔ WGS84 座標轉換 | 現況底圖、地籍套繪失敗 |
| PyMuPDF | ≥1.24 | 讀規範 PDF、`find_tables()` | 規範查詢與公式庫的 PDF 功能失效 |
| **OpenCADStudio**（`tutumomo/OpenCADStudio` fork） | 預設 CAD 出圖後端（DWG/DXF、CTB、PDF） | 退回 `accoreconsole`／CADCraft，中文 SHX 可能亂碼；`--install` 自動安裝 |
| **Open CalcSheet Studio**（`tutumomo/Open-CalcSheet-Studio`） | 開放計算環境、交叉驗算（`tools/crosscheck/`） | 無第二套獨立算法，無法交叉驗算；`--install` 自動安裝 |

安裝：

```bash
python -m pip install -r requirements.txt
```

> **不需要**編譯器、不需要 GDAL、不需要任何系統級服務。`pyshp` 取代了 GDAL 的 SHP 讀取。

## 2. 選用但強烈建議（會影響交付品質）

| 項目 | 用途 | 沒有會怎樣 |
|---|---|---|
| **AutoCAD 2020+**（`accoreconsole.exe`）、**CADCraft CLI**（皆為**備援**） | CAD 主力是必備的 **OpenCADStudio TW**（DXF → **DWG**＋PDF 出圖）。只有 OpenCADStudio 異常或需要跨後端比對時，才設 `CIVIL_AI_CAD_BACKEND=cadcraft` 改走這兩者 | 不影響：沒有備援也能出 DWG／PDF |
| **CAD 字體庫**（`gbenor.shx`、`CHINA1.SHX`，推薦組合） | TOMO 文字樣式，中文才不會變問號 | 圖面中文顯示為替代字體；**已隨 repo 附於 `CAD_FONTS/`**，`--install`／`--configure` 會把 `*.shx` **複製進 OpenCADStudio 自己的字型夾**並設好 `fonts_folder`（§8.8）。AutoCAD 備援另需 `python tools/install_cad_fonts.py --apply`。**CADCraft 不讀 SHX**（只吃已安裝的 TTF/OTF/TTC），兩套機制不同，詳見 [`字型設定_CADCraft與AutoCAD.md`](字型設定_CADCraft與AutoCAD.md) |
| **ArtCraft 15 套** | 見 §3 | 各 App 對應的產出（xlsx／docx／pptx／PDF／3D 材質／逆向重建…）需改用其他方式 |
| **SolidCraft** | 參數化 3D（擋土牆、U 型溝等 3D 模型） | 3D 軸停用 |
| **IngeTrazo 0.6.0** | 3D 建築／土木模型、BIM→IFC4＋數量 CSV、地形剖面、比例 PDF／公尺 DXF；MCP 橋可讓智能體即時建模 | BIM／地形軸停用（其餘產線不受影響） |
| **Blender** | 3D 渲染、旋轉動畫、STL→GLB | 渲染功能停用 |
| **claude-mem**（持久記憶，選用） | 讓 **Claude Code** 跨 session 保留專案脈絡：自動摘要＋MCP 搜尋（`search`／`timeline`／`get_observations`） | 不影響任何產線功能，只是新 session 少了跨次對話的記憶；用法見 [`claude-mem安裝與使用.md`](claude-mem安裝與使用.md) |

路徑都可用環境變數覆寫，不必改程式：

```bash
CIVIL_AI_ROOT      # 專案根目錄（預設＝這個 repo 的位置）
CIVIL_AI_REGS_DB   # 規範索引 sqlite（預設 data/法規/_regs_index.sqlite）
CIVIL_AI_REGS_DIR  # 法規 PDF 目錄（預設 data/法規）
CIVIL_AI_PYTHON    # 要呼叫的 Python 解譯器（預設＝執行中的那一個）
ARTCRAFT_HOME      # ArtCraft 安裝根目錄（預設 C:\Program\ArtCraft）
AUTOCAD_HOME       # AutoCAD 安裝目錄（含 accoreconsole.exe）
SOLIDCRAFT_CLI     # SolidCraft CLI 完整路徑
INGETRAZO_HOME     # IngeTrazo 安裝根目錄（預設 C:\Program Files\IngeTrazo）
INGETRAZO_MCP      # IngeTrazo MCP 伺服器完整路徑（預設 <HOME>\ingetrazo-mcp.exe）
BLENDER            # Blender 執行檔路徑
CAD_FONTS          # CAD 字體庫目錄（預設＝專案內 CAD_FONTS/，已隨 repo 附）
CADCRAFT_FONTALT       # CADCraft：把 SHX 樣式字換成已安裝的 TrueType（只認檔名，如 msjh.ttc）
CADCRAFT_FONTFALLBACK  # CADCraft：缺字時的替代字型（只認檔名；預設會挑到微軟正黑體）
```

`python tools/project_paths.py --json` 會把上述解析結果印成 JSON，方便安裝腳本判斷。

## 3. ArtCraft 15 套（本專案實際用到的）

ArtCraft 是一套桌面創作工具（每套都有 GUI 與 headless CLI）。本專案**一律走 CLI**，
不搶使用者正在操作的視窗。安裝後的路徑慣例是 `<ARTCRAFT_HOME>/<App>/<app>-cli`。

| App | 本專案用來做什麼 | 被哪支工具呼叫 |
|---|---|---|
| **CADCraft**（備援；CAD 主力已轉 OpenCADStudio TW） | DXF／DWG／PDF／PNG 轉檔、2D 圖面編修（相容 >80% 以上 AutoCAD 功能，支援跨平台產出 DWG 格式設計圖與出圖） | `tools/a3_sheet/make_sheet.py`、`tools/acad/acc.py` |
| **GridCraft** | 工程預算書 `.xlsx` 產生與回讀驗證 | `tools/boq/boq_build.py` |
| **WordCraft** | 設計報告 `.docx` 產生與轉 PDF | `tools/report/make_report.py` |
| PdfCraft | PDF 合併／抽頁／抽文字／OCR（核對交付件） | 人工或按需 |
| DeckCraft | 簡報（成果說明會） | 按需 |
| PhotoCraft／LightCraft | 現場照片整理（施工照、竣工照） | 按需 |
| VectorCraft／DesignCraft／FigCraft | 標準圖、海報、圖示 | 按需 |
| FilmCraft／EffectCraft／SoundCraft | 成果影片、動畫、配音 | 按需 |
| **TextureCraft** | 3D 模型 PBR 材質貼圖、AO/Normal 烘焙與光追渲染（`.tcraft`、`.glb/.stl`→`.png`） | 銜接 SolidCraft／3D 成果圖 |
| **Craft Anything** | 舊工程程式（`.exe/.dll/.apk/.sqlite`）演算法逆向剖析、網站擷取與潔淨室重建 | 按需 |

**ArtCraft 建議整套安裝。其中 GridCraft、WordCraft 是交付流程的必要條件**；CADCraft 已退居 CAD 備援（主力是 OpenCADStudio TW），其餘為選用。

驗證：

```bash
python tools/project_paths.py        # ArtCraft 區塊應逐項顯示 OK 與路徑
python tools/project_paths.py --versions  # 即時查版本（不寫死在文件；僅供追溯）
python tools/selftest/regression.py  # 全案回歸（含預算書與報告軸）
```

> ArtCraft 套裝更新頻繁，**文件不固定版本號**；需要歷史基準時記到
> [`docs/已驗證環境快照.md`](已驗證環境快照.md)，相容性以冒煙測試為準。

## 4. MCP 伺服器（給 AI 智能體用的介面）

本專案預期透過 MCP（Model Context Protocol）把工具暴露給 AI。缺了不會影響命令列，
但 AI 就得改用 shell 呼叫。

| MCP | 用途 | 是否必要 |
|---|---|---|
| `regs` | 規範查詢：`regs_ask`／`regs_search`／`regs_clause`／`regs_formula`／`regs_table` | **建議**（AI 查規範的主要入口） |
| `cindy_memory` | 跨 session 的持久記憶（專案決策、使用者偏好） | 選用 |
| `autocad` | AutoCAD MCP（僅 ezdxf 後端，繪圖操作） | 選用 |
| `ingetrazo` | IngeTrazo 3D／BIM（`run_python`／`query_model`／`screenshot`／`undo`／`redo`）。**stdio 只是橋**：GUI 要開、文件要開、Extensões ▸ AI Bridge (MCP) 要啟動；一次只接一個客戶端 | 選用 |
| `opencadstudio-tw` | Open CAD Studio TW（`ocs_inspect`／`ocs_query`／`ocs_run`／`ocs_open`／`ocs_save_verified`／`ocs_render`／`ocs_audit` 等 20 個工具）。**stdio 只是橋**：`<執行檔> --mcp` 連到執行中的 TW 版 GUI，不需 token；視窗沒開就沒有工具。批次出圖仍走 `tools/acad/acc.py`（自起 `--http` 實例），不經此通道 | **建議**（AI 直接讀圖、改圖、驗圖） |
| `filesystem`／`fetch` | 檔案與網路讀取 | 選用 |

`regs` MCP 的註冊腳本：`python tools/regs/register_mcp.py`（會用 `project_paths.python_exe()`
取得正確的解譯器路徑，不寫死）。

**本機 `.mcp.json` 不進版控**（`.gitignore` 已列）：各伺服器的執行檔路徑因機器而異，
其中 `open-calcsheet-studio` 還帶著 OCSS 的 Bearer token（機密，每台安裝各自產生、
換版也會換）。repo 內改放不含機密的範本 [`.mcp.json.example`](../.mcp.json.example)，
新機器照下列順序產生真正的 `.mcp.json`：

```bash
cp .mcp.json.example .mcp.json        # Windows：copy .mcp.json.example .mcp.json
python tools/mcp/register_all.py --apply             # 自動填入 regs／blender／autocad／artcraft／ingetrazo／opencadstudio-tw
python tools/crosscheck/ocss_crosscheck.py register-mcp --apply   # 讀 TW 版 token，只寫 OCSS 這筆
python tools/crosscheck/ocss_crosscheck.py probe                 # 驗證連線
```

兩支註冊腳本都只動自己負責的條目、寫檔前先備份，範本裡的路徑 placeholder 會被實際值取代。

沒有 MCP 也完全可用，等价指令：

```bash
python tools/regs/regq.py "設計一個沉砂池"        # 主題卡
python tools/regs/regq.py --search 擋土牆          # 關鍵字
python tools/regs/regq.py --clause swc_tech 119    # 條文全文
```

## 7. 讓 AI 一次裝好（給智能體的指令範本）

把下面這段貼給 AI（Claude／Codex／Cindy 等支援 shell 的智能體）：

```
請幫我把這個 repo 的環境配置好，**要真的安裝，不要只回報**：
1. `python tools/project_paths.py`                      # 先看現況（唯讀，不安裝）
2. `python -m pip install -r requirements.txt`          # Python 依賴（在虛擬環境內）
3. `python tools/project_paths.py --install`            # 自動補裝第三方工具
   這一步會從 GitHub Releases 下載兩個必備工具的「本地化 TW 版」（來源是我自己的 fork，不要改回上游）；
   另外兩個必備工具 ArtCraft Launcher 與 Blender 它只偵測，缺了會印取得指引，請依指引幫我裝好（見下方）：
     · OpenCADStudio       ← tutumomo/OpenCADStudio（Big5 SHX 修正版，中文才不亂碼）
                              Windows 用 *-installer.msi 裝到「Open CAD Studio.TW」（msiexec /passive，可能跳 UAC）；
                              Linux 用 AppImage，命令 ~/.local/bin/opencadstudio-tw
     · Open CalcSheet Studio ← tutumomo/Open-CalcSheet-Studio（Windows 取檔名含 .TW_ 的 setup.exe，
                              先 SHA256 校驗再 /S 靜默安裝到「Open CalcSheet Studio TW」，可能跳 UAC；
                              Linux 下載 .deb 後試 sudo -n apt-get install，需要密碼就印 sudo apt install 指令；
                              裝好後再跑一次 --install 補防黑屏啟動腳本與選單項目）
   我的電腦可能同時裝著上游版（「Open CAD Studio」「Open CalcSheet Studio」），
   專案只認 TW 版；若 project_paths.py 顯示「偵測到上游版…本專案不採用」，代表 TW 版還沒裝好。
   若它印出「以下指令需要你確認後自行執行」，把它列的 mv／sudo 指令貼給我確認。
   裝好 Open CalcSheet Studio TW 後，請提醒我「開啟 TW 版一次並在設定啟用 MCP/API」（上游版請關掉，兩版搶同一個埠 3879），
   接著執行 `python tools/crosscheck/ocss_crosscheck.py register-mcp --apply`（寫入本機 .mcp.json，
   token 不印出）與 `python tools/crosscheck/ocss_crosscheck.py probe` 驗證。
   OpenCADStudio TW 的 MCP 用 `python tools/mcp/register_all.py --only opencadstudio-tw --apply` 註冊（不需 token，GUI 開著才有工具）。
   嚴禁對 Open CalcSheet Studio 執行檔跑 --version／--help（會卡死）。
4. 缺規範資料就跑 `python tools/regs/fetch_regs.py` 再 `python tools/regs/build_index.py`；
   若 `data/臺中市建物/臺中市建物_114.7z` 尚未解壓，請就地解壓縮至 `data/臺中市建物/`。
5. 必備的 ArtCraft Launcher（storytold/craft-launcher）與 Blender 若顯示缺少，請依指引幫我裝好
   （Launcher 裝好後要在它的視窗內安裝 GridCraft、WordCraft），再重跑 `--install` 確認退出碼為 0。
   其餘仍顯示「需手動安裝」的（IngeTrazo 等選用工具），請列出指引給我看，
   並告訴我要設哪個環境變數（ARTCRAFT_LAUNCHER_EXE／BLENDER／ARTCRAFT_HOME／AUTOCAD_HOME／SOLIDCRAFT_CLI／INGETRAZO_HOME）。
   IngeTrazo 裝好後，MCP 以 `python tools/mcp/register_all.py --only ingetrazo --apply` 註冊。
6. 最後跑 `python tools/selftest/regression.py --ignore-new` 確認基準相符，
   並跑 `python tools/regs/verified_selftest.py` 確認公式庫可用。

回報時必須貼出第 3 步 `--install` 的「總結」段，證明實際安裝過而非只檢查。
不要修改 tools/ 內的程式，也不要上傳 data/ 與 out/ 內的任何檔案。
```

> **為什麼要寫「要真的安裝」**：2026-11-08 發生過一次事故——另台電腦的 AI 只執行了
> 唯讀的 `project_paths.py`，看到 OK／— 清單就回報「檢查完了」，但 OpenCADStudio 從未安裝。
> 當時專案裡**確實沒有安裝功能**，也沒有任何文件提到 `--install`。此後 `--install` 為正式入口，
> `AGENTS.md` §3 亦列為硬性檢查項。

## 8. 平台差異

| 功能 | Windows | macOS／Linux |
|---|---|---|
| 設計計算、預算書、報告、規範查詢、公式庫 | ✅ | ✅ |
| 出 DXF／PNG／SVG | ✅ | ✅ |
| 出 **DWG** | ✅（OpenCADStudio TW；備援 AutoCAD／CADCraft） | ✅（OpenCADStudio TW；備援 CADCraft，或 ODA File Converter 轉檔） |
| PDF 出圖 | ✅（OpenCADStudio TW；備援 AutoCAD／CADCraft） | ✅（OpenCADStudio TW；備援 CADCraft `run --cmd plot` 或 ezdxf matplotlib 後端） |
| ArtCraft 15 套 | ✅ | 依該套是否有 macOS／Linux 版（CADCraft/GridCraft/WordCraft 均有 Linux 版） |

### 8.5 macOS 專用配置（2026-11-07 實測建置）

## 8.7 CAD 出圖後端切換（`CIVIL_AI_CAD_BACKEND`）

`tools/acad/acc.py` 是 CAD 轉檔／出圖的**唯一入口**（`to_dxf()`、`to_dwg()`、`publish()`），後端由環境變數選擇：

| 值 | 行為 |
|---|---|
| `ocs`（**預設**，`auto` 同義） | OpenCADStudio（按需起 `--http` 服務）；找不到執行檔時自動退回下一列 |
| `cadcraft` | 傳統退路：有 `accoreconsole` 用它，否則 `cadcraft-cli`；OCS 異常或要跨後端比對時用 |

> **2026-11-10 預設由 `cadcraft` 切回 `ocs`**（2026-11-08 因舊版 OCS 在 Linux 出圖中文亂碼而改回，見 `docs/CAD引擎選型_OpenCADStudio與CADCraft.md` §13）。
> 重編譯版 OCS 在 Windows 實測：中文 SHX 正確、線寬符合規定、E1~E18 0 錯誤、DWG 往返保住 `TOMO_PLOTSTYLE`。
> **Linux／macOS 尚未以新版重測**——換到那些平台第一次出圖，務必把 PDF 轉 PNG 用眼睛看中文，不要只看檢核器退出碼（亂碼時頁數、尺寸、黑白、線條位置都一致，`check_delivery.py` 抓不到）。

```bash
# 預設即 OCS；要強制走傳統路徑：
CIVIL_AI_CAD_BACKEND=cadcraft python tools/a3_sheet/make_sheet.py --model x.dxf --scale 600 --out y.dxf --publish
# 指定其他位置的 OCS：
OPENCADSTUDIO_EXE=<執行檔路徑> python tools/acad/acc.py publish x.dxf --pdf
```

**OpenCADStudio 執行檔解析**（`project_paths.opencadstudio_exe()`，**只認 TW 版、不退回上游；嚴禁在程式或文件寫死安裝路徑**）：
`OPENCADSTUDIO_EXE` → Windows 於 `ProgramFiles`／`LOCALAPPDATA` 等環境變數所指根目錄下，找「去空格／點／連字號、不分大小寫」後**完全等於** `opencadstudiotw` 的資料夾（即「Open CAD Studio.TW」）內的 `OpenCADStudio.TW.exe`（MSI **不寫入解除安裝登錄的 InstallLocation**，只能靠名稱比對）→ macOS 同名 `.app` → Linux `~/.local/bin/opencadstudio-tw`、`~/.local/opt/opencadstudio-tw-*` → PATH 的 `opencadstudio-tw`。
上游「Open CAD Studio」與舊的 `~/.local/bin/opencadstudio.cmd`（2026-11-10 前 `--install` 下載的上游 portable 包裝）**一律不採用**；舊包裝可自行刪除。設定檔夾 `%APPDATA%/OpenCADStudio` 兩版共用（fork 未改 `config_dir()`），所以 §8.8 的字型／CTB 設定不分版本。

**OpenCADStudio 後端的實作要點**（`ocs_service()`／`ocs_publish()`）：

- **按需拉起**：每次呼叫開一個隨機空埠的 `--http` 服務，用完以 process group／`taskkill /T` 整組結束。實測服務約 0.5 秒就緒，不常駐。
- **token**：由 `OCS_API_TOKEN` 隨機產生並帶入子程序環境，不必解析啟動訊息。
- **`layout` 必須給圖紙名稱或 `Model`**：給 `all` 會把空的 `Layout1` 一併輸出成空白頁。
- **`plot_style` 必須傳專案 CTB 的「絕對路徑」**（`tools/acad/plot/monochrome.ctb`）：只給 `"monochrome.ctb"` 名稱時，OCS 會去 `plot_styles_folder`／`%APPDATA%\OpenCADStudio\plotstyles\` 找**同名但內容不同**的檔，線寬整組偏移（0.09／0.30 mm…），`check_delivery.py` 抓不到。絕對路徑實測有效，且不必改使用者的 OCS 設定。
- **成功判據**：回應的 `status: "waiting_input"` 是待命正常態，判成功看 `ok` 與 `result.pages`。
- **字型守衛**：`/open` 回應的 `state.missing_fonts` 非空時，`acc.py` 會在 stderr 警告（缺 SHX → PDF 中文亂碼或消失）。
- **殘留清理**：OCS 被強殺會在 DWG 旁留 `.<檔名>.ocs.lock`；覆寫既有檔時還會自留 `<檔名>.bak`（若原本就有同名 `.bak` 也會被 OCS 覆蓋）。`acc.py` 只清「本次才出現」的殘留。

## 8.8 OpenCADStudio 的 TOMO 字型與 CTB 樣式自動配置

`--install`（或 `--configure`）會把 TOMO 字型**複製**進 OpenCADStudio 自己的字型夾，並把兩個路徑寫進它的設定檔，讓它開本專案圖面時直接找到字型與出圖樣式。

**設定檔位置（跨平台）**

| 平台 | 路徑 |
|---|---|
| Linux | `~/.config/OpenCADStudio/settings.json` |
| Windows | `%APPDATA%/OpenCADStudio/settings.json` |
| macOS | `~/Library/Application Support/OpenCADStudio/settings.json` |
| 覆寫 | 環境變數 `OCS_CONFIG_DIR` |

**寫入的兩個鍵**

```json
{ "settings": {
    "fonts_folder":       "<OCS 設定夾>/fonts",
    "plot_styles_folder": "<專案根>/tools/acad/plot"
} }
```

- **字型是複製，不是指向專案**：把 `CAD_FONTS/` 的 `*.shx`（`gbenor.shx`、`CHINA1.SHX`、`CHINESE.SHX`…）複製到 `<OCS 設定夾>/fonts/`（檔名不分大小寫比對），之後搬動或刪除專案資料夾，OCS 仍找得到字型。
  目的檔已存在且內容不同時，舊檔先另存 `<檔名>.bak` 再覆蓋；內容相同則略過（可重複執行）。複製失敗才退回直接指向 `CAD_FONTS/`。
- **出圖樣式只指向、不複製**：OCS 自帶一份內容不同的 `monochrome.ctb`，複製會蓋掉它；`acc.py` 出圖時另以專案 CTB 絕對路徑傳入。
- 只覆蓋這兩個鍵，其餘設定原樣保留；寫入前先備份為 `settings.json.bak`。

**為什麼一定要設**：OCS 這兩個鍵預設是 `null`，開 TOMO 圖面會出現
`Missing fonts: CHINA1.SHX, gbenor.shx`，且無法套用 `monochrome.ctb`。
設定後即時生效，不必重啟。

**驗證方式（不看警告文字，直接讀 API 狀態）**

```bash
python tools/project_paths.py --configure          # 寫入設定
# 之後用 REST 開一次含 TOMO 的 DXF，檢查 state.missing_fonts
```

實測對照（同一份 TOMO 案圖，只改 `fonts_folder`）：

| `fonts_folder` | `state.missing_fonts` |
|---|---|
| `null` | `["china1.shx", "gbenor.shx"]` |
| `CAD_FONTS/` 或其複本 `<OCS 設定夾>/fonts`（兩檔齊備） | `[]` |

兩列都實跑過，證明驗證不是假陽性。
