## 2. 共通執行規則

所有指令都在 `D:\公司案件.AI` 執行，並指定 UTF-8：

```powershell
$env:PYTHONIOENCODING='utf-8'
& 'C:\Python312\python.exe' -E -P -X utf8 <工具路徑> <參數>
```

退出碼 `0` 代表工具判定通過；`1` 代表有未通過項或輸入找不到可用斷面；
`2` 代表命令列參數錯誤。不要把「程式有輸出」當成通過。

```powershell

  'cases\擋土牆3m懸臂式\case.json' --size --json
```

`--size` 目前只支援重力式、懸臂式；半重力式必須提供完整斷面

- 重力式／懸臂式：`wall_type`、`height_m`、`stem_thickness_m`、`base_width_m`、
  `base_thickness_m`（懸臂式）。
- 半重力式：另加 `top_width_m`、`front_batter_ratio`、`toe_projection_m`、
  `toe_soil_depth_m`，可加 `back_batter_ratio`。

## 4. 箱涵

單孔：

```powershell
& 'C:\Python312\python.exe' -E -P -X utf8 tools\design\box_culvert.py `
  --cell-count 1 --clear-width 3 --clear-height 2.5 `
  --wall 0.35 --top 0.40 --bottom 0.45 --cover 0.60 `
  --design-q 2.5 --slope 0.005
```

三孔：

```powershell
& 'C:\Python312\python.exe' -E -P -X utf8 tools\design\box_culvert.py `
  --cell-count 3 --clear-width 3 --clear-height 2.5 `
  --wall 0.35 --top 0.40 --bottom 0.45 --cover 0.60 `
  --design-q 5 --slope 0.005
```

需要地下水位或承載檢核時加 `--groundwater 1.0`、`--bearing-allow 200`；
需要地震側向土壓時加 `--kh 0.15`。

進口／出口控制（公路排水設計規範 §6.2、附錄 N／O）：

```powershell
& 'C:\Python312\python.exe' -E -P -X utf8 tools\design\box_culvert.py `
  --cell-count 3 --clear-width 3 --clear-height 2.5 --length 20 `
  --design-q 5 --slope 0.005 `
  --inlet wingwall_30_75 --tw 1.0 --hw-allow 3.0
```

`--inlet` 省略時只做曼寧正常水深檢核；填了才會算進口控制（HDS-5 迴歸式）
與出口控制（Hw = Hf + h0 − LS），並取兩者較大值當設計上游水深。
`--tw` 是涵底起算的下游水深，`--hw-allow` 是最高容許上游水深（由路堤容許
浸水高度決定，不是規範定值），`--ke` 可覆寫表 O-1 的進口損失係數。
單獨跑水理：`tools\design\culvert_hydraulics.py --q 5 --width 3 --height 2.5
--length 20 --inlet wingwall_30_75 --tw 1.0`。

`capacity_m3s` 是滿流曼寧上限，不是通水能力；通水能力要看進口／出口控制。

### 水面線（迴水）

```powershell
& 'C:\Python312\python.exe' -E -P -X utf8 tools\design\channel_profile.py `
  --q 0.3937 --width 0.4 --slope 0.005 --length 100 --step 20 `
```

基礎工具只做初步檢核；承載力必須來自鑽探或經核可的地質參數。提供
`settlement.layers` 時，獨立／聯合基腳會增加「總沉陷量（分層 2:1 法）」檢核。

次壓縮；多基礎差異沉陷與角變量請用 `settlement_assessment`。液化、側向樁、
筏基與土壤—結構互制仍未完成，不得宣稱完整基礎設計完成。

連線型別可用 `channel`、`pipe`、`box`、`fixed`。同一節點有多條出流時，

本版是穩定尖峰流量平衡，不含儲蓄、時間延遲、迴水與漸變水面線。

## 10. 驗證與擴充

每次修改 `tools\design\` 後跑：

```powershell
& 'C:\Python312\python.exe' -E -P -X utf8 tools\selftest\design_core_selftest.py
& 'C:\Python312\python.exe' -E -P -X utf8 tools\selftest\design_workbench_selftest.py
& 'C:\Python312\python.exe' -E -P -X utf8 tools\selftest\regression.py
```

新增工項時：

1. 先在共同核心找可重用的幾何／土壓／構架／RC／水理函式。
2. 新引擎要有封閉解或手算例、負面測試與舊案基準。
3. 回傳結果要包含 `engine`、`checks`、`pass`、`warnings`／`limitations`。
4. 在 `design_api.py` 加入 `CATALOG` 範例與 `RUNNERS`，工作台表單會自動生成。
5. 再把工具路徑加進 `tools\regs\topics.json` 的主題卡與 `AGENTS.md` 的觸發器。
6. 最後跑 `design_core_selftest.py`、`design_workbench_selftest.py`、`regq_selftest.py` 與全案回歸。

以上六步的完整版（含需求確認、不確定先問的邊界、上架驗證與回報格式）見
[`docs\設計計算器上架SOP.md`](設計計算器上架SOP.md)。
上架是否真的完成，一律以這支判定（0 FAIL 才算）：

```powershell
& 'C:\Python312\python.exe' -E -P -X utf8 tools\selftest\design_launch_check.py <id>
```

目前已知的數值邊界：

- 擋土牆舊 Excel 半重力式地震案例的合力位置在 1/3 中段之外；本工具會判 NG，
  舊表只以承載 FS 判定。**不得為迎合舊表而放寬中段檢核**，須由技師確認舊表假設。
- 所有土壤參數、地下水位、容許承載力與地震係數都必須以案件資料替換預設值。
- 箱涵、建築構架與基礎目前是初步設計／檢核，不是可蓋章的完整結構設計。
