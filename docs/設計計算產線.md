## 2. 三個會讓你算錯的關鍵（實測踩到）

### ① 梯形方向：背面（靠土側）鉛直，不是正面

第一版把重力式畫成「正面鉛直、背面放坡」——牆體質量全偏向前趾，
合力作用點永遠落在 1/3 中段之外，**底寬掃到 0.9H 仍全部 NG**（試了 78 組）。

正解：背面（靠土面）鉛直在 x=BL，正面（露出側）放坡。
同一組 H=3 m、φ=30°，底寬 1.95 m 就通過（滑動 FS=1.50、傾倒 3.86、合力 0.953 m）。
**斷面方向錯了，再怎麼加寬都不會過。**

> 這也代表：先前那張「重力式」斷面圖的幾何是錯的，已一併修正繪圖（`make_wall_section.py`），
> 現在**圖上畫的斷面與算穩定用的斷面是同一個**。

### ② 懸臂式漏算踵板覆土重量 → 任何斷面都驗不過

懸臂式的穩定主要來自**踵板上方的覆土**（x=T～BL、高 H 的土柱），不是混凝土本身。
漏算這塊時掃了 330 組全 NG；補上後 T=0.25／BL=1.95／BT=0.36 即通過。

### ③ 基礎承載 FS 不可重複計算

第 120 條三同時要求「應力 ≤ 容許承載力」與「FS ≥ 3」。
容許承載力本身通常已含 FS≈3，若再拿 `q_allow / q_max ≥ 3` 去判，等於乘兩次 → 永遠不過。
正解：`q_ult / q_max ≥ 3`（q_ult 未給時取 3×容許），並另判 `q_max ≤ q_allow`。

牆趾覆土的被動土壓力只計入抗滑，五個計算器的欄位與預設值見 `docs\設計工作台.md` §6.1。

## 3.4 集水區水文分析（`hydrology.py`）—— 設計流量的來源

排水溝的設計流量原本是**假設值**。本模組依水保第 16~19 條把它算出來。

| 步驟 | 條文 | 公式 |
|---|---|---|
| 降雨強度 | **第 16 條** | I_t^T / I_60^25 = (G+H·logT)·A/(t+B)^C；六個係數由 P（年平均降雨量）算出 |
| 集流時間 | **第 19 條** | tc = t1 + t2；t1 = l/v（v 採 0.3~0.6 m/s）；芮哈 t2 = L/W、W = 72(H/L)^0.6 |
| 逕流係數 | **第 18 條** | 查表（陡峻山地／山嶺區／丘陵地或森林／平坦耕地／非農業使用；無開發 vs 開發整地） |
| 洪峰流量 | **第 17 條** | **Qp = (1/360)·C·I·A**（A ≤ 1000 ha、無實測資料） |

> ⚠ 第 16 條寫「**不得小於**」該公式推估值 → 這是**下限**，設計得取更高值。
> ⚠ 第 19 條：漫地流長度上限 100 m（開發坡面）／300 m（集水區），超過須併入流下時間。

### 用法

```bat
C:\Python312\python.exe tools\design\hydrology.py ^
  --P 2000 --T 25 --area 2.0 --condition 丘陵地或森林 --l 100 --v 0.4
```

### 驗算（手算對帳）

P=2000 mm：I_60^25 = (2000/213.29)² = **87.93 mm/hr**、A=21.6293、B=55、C=0.6307、
G=0.5475、H=0.3075。l=100 m、v=0.4 → t1 = 4.1667 分。
ratio = (0.5475+0.3075×1.3979)×21.6293/(59.17)^0.6307 = **1.61212**
→ I = 87.93×1.61212 = **141.747 mm/hr**；Qp = 0.50×141.747×2.0/360 = **0.3937 m³/s**。
程式輸出 141.75／0.3937 ✓

### 對斷面的影響

原假設 Q=0.50 m³/s、內寬 0.50 m。以實際流量 Q=0.3937 m³/s 重新 `size_channel()` 選配
→ **內寬縮為 0.40 m**（Q_cap 0.544 ≥ 1.2×0.394），混凝土 39.0→37.5 m³、預算 522,044→502,624 元。

**設計流量從「假設」變成「算出來的」，斷面跟著縮小了 20%。**

## 3.5 排水溝水力計算（`channel_hydraulics.py`）

曼寧公式求等速流，並檢核五項：

| 檢核 | 準則 | 性質 |
|---|---|---|
| 通水容量 | Q_cap ≥ **1.2 × Q_design** | 工程慣例 |
| 出水高 | h_n + 出水高 ≤ 溝深；出水高 = max(0.20 m, 0.2·h_n) | 工程慣例 |
| 最小流速 | ≥ **0.6 m/s**（避免淤積） | 工程慣例 |
| 最大流速 | ≤ **3.0 m/s**（混凝土抗沖刷） | 工程慣例 |
| 福祿數 | 避開臨界流 **0.9~1.1** | 工程慣例 |
| 邊溝坡度 | > **0.2%**（山區農路 > 0.5%） | **第 78 條一(一)** |
| 側溝最小寬深 | 寬度及深度 ≥ **30 cm** | **第 78 條一(二)** |

> ✅ **已於 2026-10-28 取得條文並修正**（全文見 `data\法規\水土保持技術規範_1140507_全文.txt`）。
> 原本的「慣例值」有三處與條文不符，已全部改成條文值：
>
> | 項目 | 原慣例值 | **條文值** | 條號 |
> |---|---|---|---|
> | 最小容許流速 | 0.6 m/s | **0.8 m/s** | 第 85 條一 |
> | 最大容許流速（混凝土常流水） | 3.0 m/s | **4.57~6.10 m/s** | 第 85 條二(一) |
> | 出水高 | 0.20h | **0.25h**，最小 20 cm | 第 86 條 |
>
> 仍屬慣例者僅兩項：曼寧 n（第84條只給公式）、容量安全係數 1.2（規範未規定）。
> 詳見 `docs\水土保持技術規範_取得與條文庫.md`。

工作台的 `manning_n` 已提供材料常用範圍的下拉預設（混凝土、塑膠管、
漿砌／乾砌塊卵石、草溝／土溝），旁邊仍保留可自由輸入的數字框。第 84 條
沒有固定 n 值；特殊襯砌、淤積、植生與維護條件應由設計者選定並記錄依據。

### 第 78 條：橫向排水與涵管

| 功能 | 條文 | 實測 |
|---|---|---|
| `cross_drain_count(L)` | 第 78 條二(一)：橫向排水每 150 m 一處 | L=100 → 1 處；L=380 → 3 處 |
| `check_culvert(Q, D, n, S)` | 第 87 條：不滿流，水深 ≤ 0.75D | Ø0.60 → Q_cap 0.3676 m³/s（不足 0.6） |
| `size_culvert(Q, n, S)` | 反推最小管徑 | Q=0.5 → **Ø0.80 m**（Q_cap 0.7917） |

涵管容量採圓弓形斷面積（水深 h = 0.75D）：
`A = (D²/8)(θ − sinθ)`、`θ = 2·acos(1 − 2h/D)`、`P = Dθ/2`。
手算核對：Ø0.6、h=0.45 → θ=4.1888 rad、A=0.2275 m²、P=1.2566 m、R=0.1810 m、
Q=(1/0.014)×0.2275×0.1810^(2/3)×√0.005 = **0.3676 m³/s**，程式輸出 0.3676 ✓

`cross_drain_count` 已進 `qty_models` 的 channel 模型，會出現在數量表與預算書工項。

### 用法

```bat
:: 檢核既有斷面
C:\Python312\python.exe tools\design\channel_hydraulics.py --Q 0.5 --b 0.5 --h 0.9 --S 0.005

:: 反推通過檢核的最小斷面

```

b=0.60、h=0.90、S=0.5%、n=0.014：A=0.5400 m²、P=2.400 m、R=0.2250 m
→ Q = (1/0.014)×0.5400×0.2250^(2/3)×√0.005 = **1.0090 m³/s**，程式輸出 1.0090 ✓

## 3.6 RC 構材配筋設計（`rc_design.py`）

擋土牆**莖板**與排水溝**溝壁**的配筋設計（每公尺長）。

| 項目 | 公式 | 檢核 |
|---|---|---|
| 撓曲 | Mn = As·fy·(d−a/2)，a = As·fy/(0.85·fc'·b) | **φMn ≥ Mu**（φ=0.9） |
| 剪力 | Vc = 0.17·√fc'·b·d | **φVc ≥ Vu**（φ=0.75） |
| 最小鋼筋 | As,min = max(0.0018bh, 1.4bd/fy) | 取較大者 |
| 裂縫 | Gergely-Lutz：w = 2.2·β·fs·∛(dc·A)/Es | **w ≤ 0.3 mm** |

> ⚠ **規範依據**：《水土保持技術規範》第 120 條四只說「牆身應力須在材料容許應力範圍內」，
> 沒有配筋計算式。配筋須依《混凝土結構設計規範》。本工作區已取得
> **100.06.09 版**全文並對帳撓曲、剪力、最小鋼筋與牆鋼筋章；現行 **112.08.10 版**
> 也已取得，但 ACI 318-19 重編後的新舊條號對照尚未完成，引用前仍須核對。

### 用法

```bat
C:\Python312\python.exe tools\design\rc_design.py cases\擋土牆3m懸臂式\case.json
```

| 牆身厚 | Mu | 撓曲 | 剪力 | 裂縫 | 判定 |
|---|---|---|---|---|---|
| 0.25 m | 45.9 | φMn 46.8（98%） | OK | **0.463 mm** | ✗ 裂縫超限 |

### 兩個踩到的坑

1. **`fs` 不可一律取 0.6·fy**：那會把本來合格的配筋判成不合格。
   應由服務載重反算 `fs = M/(As·0.9d)`，上限才取 0.6fy。
2. **重力式不需要「撓曲」配筋**：它是質量混凝土，靠自重穩定；但仍配
   **名目構造鋼筋**（見 §3.6.1），第 8 章須說明「非由強度計算控制」，
   而不是硬套撓曲設計、也不是寫「無須配筋」。

### 3.6.1 牆型分流 —— `design_wall_rebar()`

> **工作台（2026-11-04 起）**：`wall_stability` 已更名「擋土牆穩定與配筋」，
> 重力／半重力／懸臂三型的穩定與配筋同頁輸出（可設 fc′、fy、保護層、
> 主筋與構造筋），檢核表包含撓曲、剪力、裂縫；`size: true` 的候選斷面

`regression.py` 都各自直接呼叫 `design_cantilever_stem()`，導致 3 m 重力式

### 底板（趾板／踵板）配筋 —— `design_base_slab()`

以**牆身為固定端之懸臂板**考慮，依基底反力 q(x) 與覆土／自重之淨壓力積分求彎矩：

| 部位 | 淨壓力 | 說明 |
|---|---|---|
| 踵板（x=T~BL） | w = (γs·H + γc·BT) − q(x) | 上方覆土向下、基底反力向上 |
| 趾板（x=0~T） | w = q(x) − γc·BT | 僅底板自重向下 |

`q(x)` 由 `retaining_wall.analyse()` 的 q_max／q_min 與偏心距重建；`|e| > BL/6` 時
受壓長度取 `Lp = 3·(BL/2 − |e|)`、三角形分佈。

積分（自由端往固定端）：`V(x) = ∫w·dξ`、`M(x) = ∫w·(ξ−x)·dξ`（Simpson，n=2000）。

## 3.7 邊坡穩定分析（`slope_stability.py`）

業務範疇（道路／排水溝／擋土牆／**邊坡**）中，邊坡是最後一個沒有計算模型的類別。
沒有計算就等於遇到邊坡案只能憑經驗給坡度 —— 與先前擋土牆「斷面在數學上不成立」同類。

### 條文

**第 72 條**：邊坡穩定係以水土保持處理使邊坡不致崩塌、地滑、土石流。

**第 73 條**：規劃設計時應進行邊坡穩定分析，並達下表最小安全係數：

| 階段 | 平時 | 地震 | 暴雨 |
|---|---|---|---|
| 永久性 | **1.5** | **1.1** | **1.2** |
| 臨時性 | **1.2** | **1.0** | **1.1** |

### 方法

| 方法 | 適用 | 公式 |
|---|---|---|
| 無限邊坡法 | 滑動面平行坡面、坡長遠大於深度 | FS = [c + σ'·tanφ] / τ，σ' = γz·cos²β − u |
| 圓弧滑動（Fellenius） | 均質邊坡整體穩定 | FS = Σ(c·l + N'·tanφ) / ΣT |
| 容許坡角反算 | 設計用 | 對坡角二分求解 |

### 手算對帳（無凝聚性封閉解）

H=5 m、β=30°、c=0、φ=35°：

```
封閉解 FS = tan35° / tan30° = 0.7002 / 0.5774 = 1.2128
程式無限邊坡法             FS = 1.213   ✓
```

圓弧法同案 FS = 1.352 —— **高於**無限邊坡，符合力學預期：無凝聚性土壤的臨界滑動面是
平行坡面的無限長平面，圓弧滑動不是最不利。

### 踩到的坑

1. **圓弧的座標系搞混**：坡趾在原點、坡面往右上、坡頂平台在 x ≥ H/tanβ。第一版把坡頂
   寫成 x ≤ 0，搜尋到的圓全部浮在地表上方 → 「找不到有效滑動圓」。
2. **圓心與半徑獨立搜尋是錯的**：圓弧若不通過坡趾就不會切進坡面。改用**坡趾圓族**
   （R = √(xc²+yc²)，只搜 xc、yc）。
3. **`inside` 是升冪，`seg[0]` 是最小 x**：寫成 `x_from, x_to = seg[0], seg[-1]` 會讓
   跨度變成負值 → 整族圓被判無效（找得到圓卻全部回 None）。
4. **例外要往保守倒**：`max_stable_angle` 曾把「找不到滑動圓」當成安全 → 一路推到 89°；
   改用無限邊坡法又因陡坡 τ→0 使 FS→∞ → 同樣 89.5°。最後改為圓弧法二分 +
   幾何無解視為不穩定，並在「FS 從未掉到需求值」時回傳 `None`（坡角非控制因素），
   不再把搜尋邊界 73.3° 當成答案。

### 用法

```bat
C:\Python312\python.exe tools\design\slope_stability.py ^
  --height 5 --angle 30 --c 0 --phi 35 --condition 平時
```

### 已知限制

- 圓弧法採 **Fellenius**（略保守於 Bishop），且只搜**坡趾圓**；陡坡的「面圓」可能更不利。
- 地下水以 `u = γw·z_w·cos²β` 近似，未做滲流網分析。
- 土層均質；分層土、軟弱夾層須另行分析。
- 土工參數（c、φ、γ）預設值是假設值，**正式設計須以鑽探報告替換**。

## 3.9 沉砂設施容量（`sediment_basin.py`）—— 從土壤流失量到池子尺寸

- 其他 0.8−0.2（不透水）= 0.6 ha：USLE 8.6 m³，下限 30×0.6 = 18 m³ → 採 18

| 池壁／底板配筋 | 呼叫 `rc_design.py` 的撓曲、剪力、裂縫與牆最小鋼筋公式 | 主筋、次要筋、`φMn`、`φVc`、裂縫寬度 |
| 空池浮力 | `FS=(底板自重＋池壁自重)/地下水浮力`；底板另以 `wL²/12` 條帶估算 | 上浮量、自重、淨上浮、FS |
| 孔口出水 | `Q=Cd·A·√(2gh)`；未指定孔徑時反算需求直徑 | 需求孔徑、採用孔徑、容量 |
| 矩形溢流堰 | `Q=Cw·L·H^1.5`；未指定堰長時反算需求長度 | 需求堰長、採用堰長、容量 |

`Cd=0.62`、`Cw=1.84`、`γw=9.81 kN/m³`、`γc=24 kN/m³` 是常用工程值，**不是水土保持技術規範明定值**。
孔口與溢流堰預設各自以完整 `--design-q` 檢核，不以兩者容量相加；`--design-q` 應由水文分析或排水路設計流量取得。

```bat
C:\Python312\python.exe -E -P -X utf8 tools\design\sediment_basin.py ^
  --area 2.0 --excavated 1.2 --impervious 0.2 --Am 40 --depth 2 ^
  --structure --wall-t 0.25 --bottom-t 0.25 --groundwater-head 0.5 ^
  --design-q 0.10 --outlet-head 1.0 --overflow-head 0.30
```

限制：

1. 結構檢核目前只計水壓力，**未計池外土壓力、地震、施工載重、溫度收縮與滲流**。
2. 底板用四周固定單向條帶 `wL²/12` 保守估算，未做版殼有限元素分析。
3. 未檢核錨定、搭接、剪力筋、基礎承載與開挖穩定。
4. 出水口未計尾水淹沒、阻塞、攔污柵與消能；出水口底高仍須依排水路常水位另行檢核。
5. 無地下水資料時浮力檢核會明確標示「未執行」，**不得當作已通過**。

### 三個坑

1. **下限不隨年期放大**：250／30 m³/ha 是「設計容量下限」，年期只乘 USLE 的計算量。
2. **不透水先扣非開挖部分**：兩者下限不同（250 vs 30），扣錯邊會少算容量。
3. **參數不可代猜**：Rm／Km／LS 要用當地值（第 35 條明定），C、P 低於 0.05／0.5 會被擋下。

> ⚠ 第 92 條沒有寫計算年期。程式以 `--years` 乘 USLE 年產量（預設 1 年），**要在報告寫明採用年期**。

## 3.10 箱涵逐面配筋與車載重（`box_culvert.py` 0.5）

### 來源與決策

配筋配置邏輯取自 `tools.excel\` 的 5 個箱涵計算檔：

| 檔案 | 用途 |
|---|---|
| `箱涵(單孔).xls` | 單孔 3×3 範例、底版／頂版／側牆配筋 |
| `箱涵(單孔、雙孔).xls` | 單孔與雙孔拓撲、各點配筋 |
| `箱涵(雙孔、三孔).xls` | 雙孔與三孔拓撲、中間牆溫度鋼筋、縱向配筋 |
| `箱涵(單孔、雙孔、四孔).xls` | 多孔拓撲與斷面分組 |
| `箱涵全.xls` | 上列內容的整合版 |

舊檔採 ASD（`fs=1400 kgf/cm²`、`fc=94.5 kgf/cm²`），本工具**只沿用「哪一面受拉、分佈筋、配筋表」的配置邏輯**，鋼筋量與筋號不照抄；一律以現行 RC 模組的 LRFD 重新設計。舊檔常見的 `D16@20 + D13@20` 這類高鋼筋量，是 ASD 容許應力下的結果，不能直接當成今日結論。

### 車載重（0.5 新增）

舊版只在程式裡藏一個 `traffic_load_kpa=10`，工作台看不到也改不了；這不是 Excel 的 H-20／H-20 S-16／40T 拖車。0.5 版改成可選車型，並把換算依據一起輸出：

| `traffic_type` | 工作簿公式 | 施加方式 |
|---|---|---|
| `none` | 無車載 | 只計土壓、上載與自重；報告會警告 |
| `h20` | 後輪 7.25 t、衝擊 30%；每輪傳佈面積 `(1.065+0.707Hc)×3.30 m²` | 頂版均佈載重 |
| `h20_s16` | `P=7.3 t`；`L=(1+3/4)Hc`（Hc>2.43 再加 4.25）；`W(n)=(1+3/4)Hc+1.8n+1.2(n-1)`，三／四車道乘 0.9／0.75；`WL=n×4P/(L×W)` | Hc>0.6 m 以均佈；Hc≤0.6 m 保留 `E=1.2+0.06s` 局部輪壓 |
| `trailer_40t` | 40T 拖車後輪 `p=40×0.4/2=8 t`；`E=1.2+0.06s`；覆土 <0.6 m 衝擊 30%；`Pwh=p(1+i)/E` | 頂版局部輪壓，逐孔移動求彎矩包絡 |
| `custom` | 使用者指定 `traffic_load_kpa` | 頂版均佈載重 |

數值對帳（1 tf = 9.80665 kN）：

- H-20、Hc=0：`7.25×1.30/[(1.065+0.707×0)×3.30]=2.6817 t/m²=26.30 kPa`
- H-20 S-16、Hc=2.0 m、四車道：`16×7.3/(3.5×10.9125)=3.0581 t/m²=29.99 kPa`
- 40T、s=4.0 m：`E=1.44 m`、`8×1.3/1.44=7.2222 t/m²=70.82 kPa`

> 工作簿把 `Pwh` 當成頂版整片均佈（總載重約為輪載的 span/E 倍，偏保守）；
> 程式改以同強度 `7.2222 t/m²` 局部作用於寬度 `E`，並逐一放在各孔頂版取
> 內力包絡。局部輪載不另計側向土壓。若要完全復刻工作簿的整片均佈，可把
> `traffic_type` 設為 `custom` 並直接輸入該 kPa 值。

### 配置邏輯

| 構材 | 受拉面與彎矩 |
|---|---|
| 頂版 | 外側（覆土側）取支承處負彎矩；內側（涵內側）取跨中正彎矩 |
| 底版 | 外側（基礎土側）取支承處正彎矩；內側取跨中負彎矩 |
| 外側牆 | 背土面取支承處彎矩；涵內面取牆中彎矩 |
| 中間牆 | 左面、右面分別取正負彎矩；不再只用溫度鋼筋帶過 |
| 縱向分佈筋 | 版 `0.0018·b·h`、牆 `0.0020·b·h`，**總量分置內外兩面** |

每個受拉面輸出：筋號、間距、實配 `As`、`φMn`、裂縫寬度 `w`、控制因素（撓曲強度／最小鋼筋／裂縫控制／最大間距）與 OK／NG。彎矩由 `frame_analysis.MemberResult.moment_diagram_knm` 的 101 點彎矩圖取正、負包絡，不是只取桿端最大彎矩。

軸彎互制依**實際受拉面**定向：先找彎矩最大的面，再以該面為受拉面、另一面為壓力面建立 `layer_areas`。不可像早期版本一樣「兩個彎曲方向取較小值」，否則上下配筋不同時會把受拉面在配筋較多側的工況誤判為 NG。

### 數量 → 預算 → 報告 的一致性（2026-11-03）

箱涵的數量、預算、報告與設計閘門**共用同一組參數與同一組數量鍵**：

| 環節 | 來源 | 不可再做的事 |
|---|---|---|
| 分析參數 | `case_core._box_culvert_kwargs()` | 各處自己組 `traffic_type`／`cover_mm` 預設值 |
| 鋼筋量 | `quantities.rebar_kg_design`（含 6% 搭接損耗） | 用 `rebar_kg`（含鋼量假設值）進預算或報告 |
| 模板量 | `quantities.formwork_m2`（含兩端端模） | 另寫一套 `n(2H+B)` 舊公式 |
| 每延米 | `rebar_kg_per_m`／`rebar_kg_per_m_net`／`formwork_m2_per_m` | 只用總量回推 |

案件 `boq.items` 的鋼筋工項必須是 `qty_from: "rebar_kg_design"`；報告數量表
與本文的每延米、淨量、含損耗量、總量都由同一份結果產生。實測（三孔
3.0×2.5、L=20 m、覆土 0.6 m、H-20）：

### 限制

1. 未含三維角隅補強、施工縫、開口補強、錨定／搭接長度細節與正式配筋詳圖。
2. 鋼筋量是依理想化排筋計數的概估，不是裁剪表；正式數量須依配筋圖重算。
3. 土工參數（`γ=18 kN/m³`、`φ=30°`）須以鑽探報告替換；車載重須依道路等級選 H-20／H-20 S-16／40T，不能把 `none` 當成「已檢核」。
4. 軸彎互制為單軸、兩層鋼筋的初步檢核；雙向彎矩、剪力牆行為、地震載重組合與二階效應未納入。
5. 保護層採單一 `cover_mm`；底版貼地澆置依 112 年版表 20.5.1.3.1 宜 75 mm，採 50 mm 時須確認實際暴露條件與業主規定。
6. 車載重與其他載重共用 `load_factor`（預設 1.7），尚未拆分 1.2D+1.6L 或 AASHTO 1.25DC+1.75LL；正式設計須依採用規範重算載重組合。
7. 模板量只計涵內側（頂版底面、底板頂面、外牆內面、中牆兩面）與兩端端模；
   外側貼土面、施工縫、開口與翼牆模板不計。若外側需雙面模板或免拆模板，須另行加計。
