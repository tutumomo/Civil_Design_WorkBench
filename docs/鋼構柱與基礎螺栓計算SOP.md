# 鋼構柱與基礎螺栓計算 SOP

> 版本：1.0（2026-11-02）
>
> 適用：熱軋或銲接 H 型鋼柱、露出式柱腳基板、澆置前預埋之基礎螺栓（cast-in anchor bolt）。
>
> 不適用：埋入式柱腳、SRC／CFT、鋼管柱、後置式錨栓、特殊預埋件、機械式擴底錨栓。這些型式需另依產品試驗報告或專門規範設計。
>
> 本 SOP 是計算流程與檢核清單，不取代技師簽認。正式設計須由依法登記之結構技師覆核。

## 3. Step 1：載重與載重組合

### 3.1 先決定設計法

全案擇一，**不得 ASD 與 LRFD 混用**：

- **ASD（容許應力設計法）**：載重採服務載重；檢核 `fa ≤ Fa`、`fv ≤ Fv`、比值 ≤ 1.0。`steel99` 第六(一)章、第十章多數表格屬此體系。
- **LRFD（極限設計法）**：載重採因數化載重；檢核 `Pu ≤ φPn`、`Mu ≤ φMn`。`steel99` 第六(二)章、第八章(二)有對應公式。

### 3.2 載重組合

至少檢核下列工況，並取 **柱腳彎矩最大、軸力最大、剪力最大、拉力最大** 四種控制工況：

| 工況 | ASD | LRFD |
|---|---|---|
| 靜載重 | D | 1.4D |
| 靜＋活 | D+L | 1.2D+1.6L |
| 靜＋活＋風 | D+L+W | 1.2D+1.6L+0.5W 或 1.2D+1.0W+1.0L |
| 靜＋活＋地震 | D+L+E | 1.2D+1.0E+1.0L |
| 靜載重控制＋風／地震 | 0.9D+W／0.9D+E | 0.9D+1.0W／0.9D+1.0E |

注意：

- 地震力依《建築物耐震設計規範》最新版；特殊抗彎矩構架（SMF）柱腳應依耐震規範的容量設計原則提高設計力，不得只用彈性分析值。
- 風力／地震工況的容許應力提高 1/3，僅限規範允許的項目；螺栓剪力不得提高（steel99 §10.3.4）。
- 側移構架須考慮 P-Δ 二次效應；`K` 值不得因「保守」而隨意取 1.0，須依 §4.8 的構架穩定規定。

## 4. Step 2：鋼柱斷面檢核

### 4.1 斷面分類（steel99 §4.5）

先算翼板與腹板的寬厚比：

```
翼板 b/tf、腹板 h/tw
```

判定為結實斷面、半結實斷面或細長肢材。若超過 §4.5 的 λr，須依附錄 1 計算局部挫屈折減係數 `Qs`，不得直接套用 §6.3 或 §6.2 的公式。

### 4.2 長細比（steel99 §4.4）

```
KL/r ≤ 200（受壓構材）
L/r  ≤ 300（受拉構材，受拉圓桿除外）
```

`K` 依 §4.8 決定；`r` 取挫屈平面的迴轉半徑，強軸與弱軸分別檢核。

### 4.3 軸壓容量

#### ASD（steel99 §6.3）

```
Cc = √(2π²E/Fy)

若 KL/r < Cc：
Fa = [1 − (KL/r)²/(2Cc²)]·Fy
     ─────────────────────────────────────
     5/3 + (3/8)(KL/r)/Cc − (1/8)((KL/r)/Cc)³

若 KL/r ≥ Cc：
Fa = 12π²E / [23(KL/r)²]
```

檢核：`fa = P/Ag ≤ Fa`。

#### LRFD（steel99 第六(二)章；已驗證公式 `steel99_Fcr_lrfd`）

```
λc = (KL/(πr))·√(Fy/E)

Fcr = exp(−0.419λc²)·Fy          （λc ≤ 1.5）
Fcr = (0.877/λc²)·Fy             （λc > 1.5）

φcPn = 0.85·Ag·Fcr
```

檢核：`Pu ≤ φcPn`。

### 4.4 彎矩容量

- 依 steel99 第七章計算容許撓曲應力 `Fb`（ASD）或 `φbMn`（LRFD）。
- 須判斷是否為結實斷面、是否會側向扭轉挫屈；`Lb` 超過 `Lr` 時，`Fb` 會明顯折減，不得一律取 `0.66Fy`。
- 弱軸彎矩另計；雙向彎矩須分別檢核。
- 剪力依第七章檢核腹板；`h/tw` 過大時依板梁規定。

### 4.5 梁柱互制（steel99 §8.2）

柱腳通常同時有軸力與彎矩，**不可只檢核軸壓**。ASD 採下列兩式，取最不利：

```
fa/Fa + Cmx·fbx/[(1 − fa/F′ex)·Fbx] + Cmy·fby/[(1 − fa/F′ey)·Fby] ≤ 1.0

fa/(0.6Fy) + fbx/Fbx + fby/Fby ≤ 1.0
```

其中：

```
F′e = 12π²E / [23(KLb/rb)²]
```

`Cm` 依 §8.2：

- 可側移構架、構材兩端無橫向載重：`Cm = 0.85`
- 受支撐不可側移、兩端無橫向載重：`Cm = 0.6 − 0.4(M1/M2)`（雙曲率為正、單曲率為負）
- 兩端有橫向載重：依 §8.2 或合理分析，常用 0.85（端點束制）或 1.0（兩端未束制）

若 `fa/Fa ≤ 0.15`，可用簡化式：

```
fa/Fa + fbx/Fbx + fby/Fby ≤ 1.0
```

**注意**：`Fa` 取兩個方向長細比中較小者（最大 KL/r 控制）；`F′e` 則依彎曲平面取對應的 `KLb/rb`。這是 §8.2 解說特別指出的常見錯誤。

#### LRFD 梁柱互制

LRFD 採 `Pu`、`Mux`、`Muy` 與 `φPn`、`φbMnx`、`φbMny`，並以 `B1`、`B2` 放大彎矩：

```
Pu/φPn ≥ 0.2：
Pu/φPn + (8/9)·[Mux/φbMnx + Muy/φbMny] ≤ 1.0

Pu/φPn < 0.2：
Pu/(2φPn) + [Mux/φbMnx + Muy/φbMny] ≤ 1.0
```

`B1` 為構材本身之二次效應（無側移）、`B2` 為構架側移效應；兩者不得省略。若採簡化法，須確認 `K` 值與彎矩放大已涵蓋側移效應。

### 4.6 柱腳局部檢核

- 柱端銑平，與基板密貼；不得以填隙片勉強承壓。
- 柱翼板／腹板與基板的銲道，依翼板拉力、腹板剪力與彎矩設計；銲道不得只按「最小銲腳」施作。
- 基板下方混凝土承壓另見 Step 3。
- 若柱腳有加勁板，須檢核加勁板與柱、基板的銲道及局部挫屈。

## 5. Step 3：柱腳基板

### 5.1 混凝土承壓（steel99 §10.9）

#### ASD

```
全面積承壓：Fp = 0.35 fc′
承壓面積小於混凝土全面積：Fp = 0.35 fc′·√(A2/A1) ≤ 0.7 fc′
```

其中：

- `A1` = 鋼材在混凝土上的承壓面積（通常取基板面積 `Bp×Np`，但不得大於墩座斷面積）。
- `A2` = 在支承面上與載重面積同心、幾何相似的最大面積；依 1 垂直：2 水平擴散至墩座頂或基腳頂。
- `A2/A1 ≤ 4`（即 `√(A2/A1) ≤ 2`）。

#### LRFD（已驗證公式 `steel99_concrete_bearing_Pp`）

```
φcPp = 0.6 × 0.85 fc′ A1 √(A2/A1) ≤ 0.6 × 0.85 fc′ A1 × 2
```

檢核：`Pu ≤ φcPp`。

### 5.2 基板尺寸

基板平面尺寸先由下列條件決定，再用承壓與厚度檢核：

- `Bp ≥ bf + 2×邊距`、`Np ≥ d + 2×邊距`。
- 錨栓孔中心至板邊：至少 `1.5db`，且需容納墊圈／墊鈑；實務常取 `2db` 以上。
- 錨栓孔徑：標準孔約 `db + 2~3 mm`；加大孔須用厚度足夠的墊鈑，墊鈑孔徑與螺栓徑匹配。
- 錨栓 gauge 與柱翼板、腹板位置不得衝突；扳手操作空間須足夠。

### 5.3 基板厚度

基板厚度不是用「承壓面積」決定，而是用 **柱端外伸懸臂的彎矩** 決定。依 AISC Design Guide 1 的懸臂法（我國鋼構造規範未給基板厚度公式，這是工程慣用方法，計算書須註明）：

```
單位寬度彎矩 m = q × l² / 2
```

其中 `q` 取基板下最大承壓應力，`l` 取柱翼板外緣（或腹板外緣）至基板邊的懸臂長度。取翼板外伸與腹板外伸兩者較大者。

```
ASD： t ≥ √(6m / Fb)，Fb 可取 0.75Fy（基板受撓曲）
LRFD：t ≥ √(4m / (φb Fy))，φb = 0.90
```

另加腐蝕裕度（戶外常取 2 mm，依設計要求）與施工公差。若算出的厚度過大，應加勁板或加大基板，不得任意用薄板。

### 5.4 灌漿與剪力傳遞

- 基板下以無收縮水泥砂漿填實，厚度一般 30~50 mm；須留排氣孔，灌漿後不得有空隙。
- 摩擦力 `V ≤ 0.5 μP`（steel99 §10.10.2）：
  - 埋入灌漿內：μ = 0.9
  - 與硬化混凝土面齊平：μ = 0.7
  - 灌漿面高於混凝土面（外灌漿襯墊）：μ = 0.55
- 地震反復載重下，摩擦力不可靠；應以剪力榫或錨栓剪力承擔，不得把摩擦力當主要抗震路徑。

## 6. Step 4：基礎螺栓

### 6.1 配置原則

- 露出式柱腳至少 4 支錨栓（多數情況）；實際數量依拉力與彎矩決定。
- 錨栓應對稱於柱腹板與翼板；拉力側與壓力側分開檢核。
- 邊距與間距要能形成完整的 45° 混凝土應力錐；若邊距不足或錨栓太近，應力錐會重疊或被邊界截斷，容量必須折減。
- 錨栓埋深 `hef` 先由混凝土拉破與錨頭承壓決定，再檢核最小值。螺紋錨栓依 rc112 §17.3.4 有 `5da ≤ hef` 的適用範圍；實務常取 20~30db，但仍須以拉破檢核為準。

### 6.2 拉力需求

柱腳受 `P`（壓力）與 `M` 時，拉力側錨栓的拉力不是單純 `M/d`。正確做法是「基板剛性、混凝土僅受壓、錨栓僅受拉」的應變相容分析：

1. 假定中性軸深度 `x`（自混凝土受壓邊起算）。
2. 混凝土受壓合力 `C`：ASD 用三角形分佈，LRFD 用 0.85fc′ 矩形塊。
3. 拉力側錨栓應變 `εi = εc·(di − x)/x`，拉力 `Ti = Ab·Es·εi`（不得超過鋼材容量）。
4. 以 `ΣF = 0`、`ΣM = 0` 迭代求 `x` 與 `Ti`。
5. 取各載重組合中 **單支錨栓最大拉力** 與 **拉力側總拉力**。

初步配置可用簡化式估算（僅供初選，不得直接當定案）：

```
拉力側總拉力 T ≈ M/d_b − P/2
```

`d_b` 取拉力側錨栓列至壓力側錨栓列的距離，僅適用對稱 4 支配置的初選。若 `P` 很小或為拉力，`−P/2` 會變成加項，更不能忽略；定案仍須用上述混凝土受壓塊迭代。

### 6.3 錨栓鋼材拉力容量

#### ASD（steel99 表 10.3-2）

| 錨栓種類 | 容許張應力 Ft（tf/cm²） | 容許剪應力 Fv（tf/cm²） |
|---|---:|---:|
| A307 | 1.40 | 0.70（承壓式） |
| F10T／S10T，螺紋在剪力平面 | 3.62 | 1.87（承壓式） |
| F10T／S10T，螺紋不在剪力平面 | 3.62 | 2.68（承壓式） |
| 螺牙桿件符合 §3.4，螺紋在剪力平面 | 0.33Fu | 0.17Fu |
| 螺牙桿件符合 §3.4，螺紋不在剪力平面 | 0.33Fu | 0.17Fu |

檢核：`T ≤ Ft·Ab`（單支），`ΣT ≤ Ft·Ab·n_t`（拉力側）。

#### LRFD（已驗證公式 `steel99_bolt_tension_Rn`）

```
Rn = 0.75·Ab·Fu
```

依 steel99 第十(二)章的強度折減係數檢核 `Tu ≤ φRn`。若採 ASTM A325／A490，容許應力須改用表 C10.3-2，不得直接套 F10T 的值。

### 6.4 混凝土拉破與拔出

#### ASD（steel99 §10.10.2 解說）

混凝土 45° 應力錐的抗拉出強度：

```
Tc = 0.53√fc′ × A_cone
```

其中 `fc′` 用 kgf/cm²，`A_cone` 用 cm²，`Tc` 為 kgf。檢核：

```
Tc ≥ Ft × Ab × n_t
```

`A_cone` 的算法：

- 單支錨栓：自錨頭或錨板邊緣以 45° 向上擴散至混凝土面，`A_cone ≈ π·hef²`。
- 群組：取各錨栓應力錐的聯集，**重疊部分只能算一次**。
- 靠近墩座邊緣或基腳頂面：超出混凝土邊界、或受厚度限制的部分要扣除。
- 邊距小於 `hef` 時，應力錐被截斷，容量會大幅下降；必要時加錨鈑、加鋼筋或加大墩座。

另檢核錨頭承壓：錨頭（或錨板）承壓面積 `A_brg` 須足夠，避免混凝土局部壓碎。可依 rc112 §17.6.3.2.2(a) 的 `Np = 8·A_brg·fc′` 標稱值檢核，或依產品型錄的承壓試驗值；不得只用錨桿斷面積充當承壓面積。

#### LRFD 與 rc112 的適用界限

- rc112 第 17 章適用於單根錨栓、部分後置錨栓等；**§17.1.5 明文排除「多根錨栓端部連接於單一埋設鋼板」的特製預埋件**。柱腳基板正是多根錨栓連到同一塊基板，因此不能直接把第 17 章的單錨栓公式整套套用。
- 柱腳混凝土側建議以 steel99 §10.10.2 的 45° 應力錐法（ASD）為主要依據；若採 LRFD，須以試驗、有限元素或經技師認可的錨栓群模型補充，並在計算書說明。
- 若柱腳設剪力榫，混凝土側可依 rc112 §17.11「具剪力榫之基板」檢核；這是第 17 章中針對基板的專門節次。

### 6.5 剪力

依載重組合取柱腳最大剪力 `V`。依序檢核：

1. **摩擦力**：`V ≤ 0.5μP`（§10.10.2）。`P` 取該工況的壓力；若 `P` 為拉力或接近零，摩擦力不可計。
2. **錨栓剪力**：`V ≤ Fv·Ab·n`（ASD）或 `Vu ≤ φRn`（LRFD）。螺紋在剪力平面時用較低的 `Fv`；長接頭（>125 cm）依表 10.3-2 註 e 折減 20%。
3. **剪力榫**：若剪力大或地震反復，設剪力榫。檢核鋼板承壓、混凝土局部承壓（§10.9）與混凝土剪破（rc112 §17.11）。剪力榫與基板的銲道須能傳遞全部剪力與偏心彎矩。
4. **拉剪互制**：錨栓同時受拉與受剪時，依 steel99 表 10.3-3：
   - A307：`Ft = √(1.40² − fv²)`（tf/cm²）
   - F10T／A325／A490：依表 10.3-3 或表 C10.3-3 的橢圓互制式，隨螺紋位置不同。
   - 風力／地震組合時，`Ft` 可提高 1/3，但 `fv` 不得提高。

### 6.6 預拉力與施工

- F10T／S10T 最小預拉力依 steel99 表 10.3-1：

| 直徑（mm） | 12 | 16 | 20 | 22 | 24 | 27 | 30 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 最小預拉力（tf） | 5.9 | 10.6 | 16.5 | 19.9 | 23.7 | 30.0 | 37.1 |

- 採旋轉螺帽法、直接拉力指示器或扭力扳手；扭力控制型螺栓（TC bolt）以斷尾判斷。
- 承壓型螺栓若設計不要求預拉力，至少鎖至「緊貼狀態」（snug-tight），並在圖說註明。
- 錨栓一般採雙螺帽或防鬆螺帽；外露螺紋長度須足夠（至少 3 牙完整咬合，依規範）。
- 戶外或潮濕環境須鍍鋅、熱浸鍍鋅或塗裝；銲接錨栓須用可銲鋼材（§10.10.1 解說）。
- 澆置混凝土前用樣板固定錨栓，避免以電銲固定；若必須電銲，材質須可銲。

### 6.7 錨栓群檢核表

每一載重組合填一列：

| 工況 | P | M | V | 中性軸 x | 單支 Tmax | 鋼材容量 | 混凝土錐容量 | 剪力容量 | 拉剪比值 | 判定 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---|

`Tmax` 取拉力側最大單支；混凝土錐容量取群組聯集，不是單支容量乘支數。

## 7. Step 5：基礎與墩座

柱腳力量必須完整傳到基礎，不能只算到錨栓為止。

### 7.1 墩座

- 檢核墩座在基板下的局部承壓（§10.9）。
- 錨栓拉力由墩座垂直鋼筋、箍筋或剪力釘傳遞；以拉桿—壓桿模型或垂直鋼筋拉力檢核。
- 墩座頂部配置足夠的圍束鋼筋，避免錨栓拉力造成劈裂。
- 錨栓應錨定在墩座主筋下方，不得與主筋衝突；必要時加錨鈑或彎鉤。

### 7.2 基腳

依《建築物基礎構造設計規範》（found112）檢核：

- 基腳底承壓與傾倒、滑動安全係數。
- 沖剪、單向剪力、撓曲配筋。
- 服務載重下不得有過大拉力或零壓力區；地震工況依規範容許值。
- 沉陷與差異沉陷、角變量。

### 7.3 基礎螺栓與基礎鋼筋的互制

- 錨栓拉力會使基腳頂面產生裂縫；必要時增設頂部鋼筋。
- 錨栓邊距不足時，混凝土拉破面可能落在基腳邊緣外；加大基腳或加錨鈑。
- 剪力榫的混凝土剪破面須避開基腳邊緣與開孔。

## 9. 常見錯誤

1. **只用軸壓檢核柱**：柱腳通常由彎矩或梁柱互制控制。
2. **錨栓拉力用 `M/d` 一跳了事**：忽略軸力、混凝土受壓合力位置與群組變形。
3. **只算錨栓鋼材，沒算混凝土拉破**：鋼材很強，混凝土先錐裂。
4. **應力錐重疊卻按支數相加**：群組容量不是單支容量 × n。
5. **邊距不足卻未折減**：45° 錐被墩座邊緣截斷。
6. **地震剪力靠摩擦力**：反復載重下摩擦力不可靠，且 `P` 可能不足。
7. **基板厚度用承壓面積算**：厚度由懸臂彎矩控制。
8. **ASD 與 LRFD 混用**：載重、容許應力、折減係數全部對不上。
9. **柱腳假定與細部不一致**：圖上畫固接，計算卻用鉸接；或反之。
10. **忽略二次效應**：側移構架的 `K` 與彎矩放大未計。
11. **螺栓孔徑、墊鈑、預拉力未標**：施工現場自行放大孔，導致滑移與承壓不足。
12. **單位混淆**：`tf/cm²` 與 `MPa` 直接相加，數值差 10 倍以上。
